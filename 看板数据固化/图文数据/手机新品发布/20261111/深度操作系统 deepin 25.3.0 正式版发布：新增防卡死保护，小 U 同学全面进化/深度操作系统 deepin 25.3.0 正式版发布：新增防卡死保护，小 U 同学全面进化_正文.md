# 深度操作系统 deepin 25.3.0 正式版发布：新增防卡死保护，小 U 同学全面进化

> 来源：IT之家 ｜ 原文：https://www.ithome.com/1/025/472.htm

> 采集说明：collect_P42_手机新品.py 正文段落照录；chips机械提取、摘要照录首段。

IT之家 11 月 11 日消息，深度操作系统 deepin 25.3.0 正式版于今日发布，本次更新围绕系统稳定与性能、体验与智能、生态与适配三大方向全面升级。
小 U 同学全面进化：让 Agent OS 的系统级智能触手可及。全盘资料，一句话即可调取，你电脑里的每一份文档都能成为随时可用的知识；同时统一 MCP、Skills 与专职智能体能力入口，由小 U 同学根据任务自动调度所需能力，系统开始主动，工作自然更快一步。
系统稳定与性能大幅提升：新增防卡死保护，系统严重卡顿时仍可唤醒任务栏、启动器与系统监视器等关键组件；控制中心首页加载速度大幅提升，微信、WPS、QQ、主流浏览器等常用软件在高负载场景下依然快速启动，系统久用流畅稳定。
系统维护与数据保护更省心：磐石系统快照还原体验优化，创建快照可选择本地磁盘、U 盘或移动硬盘等存储位置，也可从指定位置选择快照回退；镜像默认集成电脑管家，检测、清理、修复一站完成，让系统维护像体检一样简单。
系统内核与硬件兼容能力进一步增强：系统内核与硬件兼容能力进一步增强：默认内核更新至 6.6.159，修复 x86、arm64、loong64 多架构安全漏洞，修复部分飞腾机型无法启动的问题；高版本内核升级至 6.18.56 版本，可在内核管理器中选择安装，以更好支持新一代硬件平台。
桌面与应用体验持续改善：任务栏可直接断开已连接设备，关机全程持续显示动画；看图新增图片编辑能力，文档查看器支持恢复阅读位置并加入三种护眼模式；文本编辑器支持支持 markdown 渲染；日历支持添加第三方日程。
IT之家附完整更新说明如下：
支持通过自然语言创建提醒、定时与周期任务，让重复事务自动执行；
支持全盘知识库，可查询已授权的本地文件内容；
统一 MCP、Skills 与专职智能体能力入口，由小 U 同学根据任务自动调度所需能力；
增强对话记忆与上下文自动摘要，支持任务排队与按工作区管理历史对话；
支持按会话独立配置权限模式，文件保存权限安全可控，减少重复审批。
