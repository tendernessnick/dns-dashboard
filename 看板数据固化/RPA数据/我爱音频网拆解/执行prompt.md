## 1. 任务定义

- **目标站点**：https://www.52audio.com/archives/category/teardowns （我爱音频网·拆解栏目；免费、免登录）
- **采集方式**：AutoGLM 浏览器代理（RPA）模拟真人浏览，**禁止任何脚本爬虫**（铁律 1）
- **新拆解判定（去重红线）**：以**原文链接比对 `索引.md` 已登记清单**为准——链接未登记过的即为新拆解（日期过滤仅作辅助）；**严禁重复采集、重复落盘已采集过的文章**。数量不定，有 N 篇采 N 篇。
- **当日无新拆解**：仍执行栏目页检查；**不落任何数据文件、不创建当日日期文件夹**，`索引.md` 登记行记"无新拆解"。看板卡显示最近已采集的文章（生成器按发布日期取最近 6 篇，与"当日是否有新稿"无关）。
- **内容范围**：拆解栏目**全量收录不过滤**（用户 2026-11-05 拍板）——耳机/音箱/手环/机器人等均收，chips 词条按文章本身的参数提炼。

## 2. 采集流程（单次 AutoGLM run 打包）

1. **前置检查**：打开栏目页确认可访问；遇验证码/风控提示 → 立即停止并汇报（铁律 1）。
2. **列表核对**：栏目列表从新到旧，按发布日期识别未采集的新拆解（对照 `索引.md` 清单）。
3. **逐篇采集**：逐篇 `extract_content` 提取正文全文（任务指令含"完整输出全文"以保证正文随结果返回），记录发布日期与原文链接；随后**分多次缓慢滚动浏览全篇，让每张产品图片都有停留帧**（供照片裁切）；页面间停留 3–7 秒；单任务页面访问上限 60 页（本任务通常 ≤ 20 页）。
4. 首次开发运行（2026-11-05）取最新 3 篇作为格式开发样本。

## 3. 落盘结构（用户 2026-11-05 指定，本条目专用）

```
数据看板构建/看板数据固化/RPA数据/我爱音频网拆解/
├── 执行prompt.md              # 本文件
├── 索引.md                    # 逐日登记 + 去重基线（AGENTS 7.4 同构）
└── <YYYYMMDD>/                # 采集当日日期
    └── <产品名>/              # 一篇文章一个文件夹，名取文章标题中的产品名（去特殊字符）
        ├── YYYYMMDD_我爱音频网_拆解_<产品名>_正文.md
        ├── YYYYMMDD_我爱音频网_拆解_<产品名>_照片N.png     # 关键配图（帧裁切），看板引用
        ├── YYYYMMDD_我爱音频网_拆解_<产品名>_配图N.jpeg   # 整页帧留档（gitignore，不入库）
        └── _meta.json         # ★结构化契约：生成数据.py 的唯一内容来源
```

- **正文 md**：文章全文原样整理为 markdown，不改动原文表述；文末固定附四行——配图清单、发布日期、原文链接、采集日期。
- **命名**：日期一律为**采集当日**；文章实际发布日期记录在 `_meta.json` 与 `索引.md`。
- **照片落盘方式**：不发起任何脚本 HTTP 请求（铁律 1 零豁免）。照片 = AutoGLM 整页视口帧内**照片区域裁切**，存 `…_照片N.png`（每篇 2–4 张）；整页帧以 `…_配图N.jpeg` 留档。网页原图 URL 未能提取时在正文 md 说明。

### `_meta.json` 契约（采集会话产出，`生成数据.py` 只搬运不猜测）

```json
{
  "产品名": "MOMAX摩米士磁吸音响保温杯",
  "品类tag": "磁吸音响",
  "发布日期": "2026-11-04",
  "原文链接": "https://www.52audio.com/archives/xxxx.html",
  "chips": ["≤6条，每条=参数或卖点短词条，数值照录原文，不换算"],
  "摘要": "两句以内中文摘要，经 humanizer-zh 润色，不添加原文之外的信息",
  "照片": ["…_照片1.png", "…_照片2.png"]
}
```

## 4. 看板产出（与每日评测的差异）

本任务**不再产出独立看板 HTML**——数据直接进主看板：

- 主看板 P91 卡（竞对同业板块）由 `看板/渲染器/70_review.js` 渲染，卡样 = 模块样板 v8 的图文卡（缩略图 + 词条 chips + 两行摘要 + 整卡超链接），配色用主看板主题变量。
- 数据链路：`生成数据.py` 扫描本目录所有 `_meta.json`，按发布日期取**最近 6 篇**，照片压缩（宽 320px JPEG）后 base64 内联 `data.js`。
- 例行运行后需手动/定时执行：`python 生成数据.py`（主项目 `看板/` 下）刷新 data.js。

## 5. 异常处理

风控即停；改版/元素丢失记录后跳过并汇报；目标缺失不编造。AutoGLM 单轮调用失败不自动重试，汇报 `[retry_suggestion]` 等待用户指示；OSS 截图下载中断时记录待补清单与 URL（同每日评测的遗留项处理）。

## 6. 定时运行

- **每日 20:40 由 ZCode 定时任务自动触发**（任务名「每日拆解·我爱音频网采集」），按本 prompt 全流程执行；人工下发任务同样适用本 prompt。
- 运行失败不自动重试，按 §5 汇报并等待用户指示。
