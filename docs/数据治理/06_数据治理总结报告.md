## 五、治理后维护 SOP

**日常更新（不变）**：双击 `更新看板.bat`（或 run_all.py + 生成数据.py）。
**改元数据**（单位/小数位/窗口/评级/口径）：改 `词条注册表.csv` 对应行 → `python 生成数据.py` → 刷新浏览器。
**加/改列（schema变更）**：按《11_固化数据存储规范》§5 迁移流程；save_row 会拒绝未迁移的写入。
**采集失败**：查 `采集日志.csv`（按 run_id 定位批次）；连续3次失败按《10_采集器开发规范》复核来源。
**缺季提醒**：`待补录.csv` 非空时按考证流程补录（行业历史考证-C.md 方法论），补齐后看板标签自动消失。
**新增采集器**：走《10_采集器开发规范》§7 checklist。
