# 看板模块化导航

[返回文档总导航](../README.md) · [项目入口与运行方法](../../README.md) · [数据治理导航](../数据治理/README.md)

本目录服务页面维护。先读当前规范，再按任务查阅UI、规划或部门机制；版本实施记录中的截图、数量及测试结果属于该次交付。

## 当前维护入口

| 文档 | 什么时候读 | 定位 |
|---|---|---|
| [00_模块化设计与规范](00_模块化设计与规范.md) | 改模块字段、卡型、布局、渲染器或构建行为 | 当前维护契约，包含后续迭代补充 |
| [v27稳定分页与译题质量](v27稳定分页与译题质量实施记录.md) | 固定阅读区、空态、中文译题质量与缓存 | 当前分页与译题契约 |
| [v26资讯分页与目录优化](v26资讯分页与目录优化实施记录.md) | 资讯左右翻页、整卡原文、议息新闻、物流并排和可收缩目录 | 当前交互依据 |
| [v25阅读与详情](v25阅读与详情实施记录.md) | 阅读样式、数值精选、历史表和数值详情 | 沿用的阅读与详情基础；资讯交互以v26为准 |
| [v24专业分析工作台设计与实施记录](v24专业分析工作台设计与实施记录.md) | 改顶部部门入口、左侧目录、概览、模块检索、图表及响应式布局 | 当前UI与交互依据 |
| [v23外部情报与部门扩展实施记录](v23外部情报与部门扩展实施记录.md) | 查外部情报边界、规划模块、预留P号与正式接数流程 | 当前规划依据；P255—P265仍须区分规划状态与实际数据绑定 |
| [v22部门子看板实施记录](v22部门子看板实施记录.md) | 查页面注册、部门复用、来源依赖、实例ID和单文件分享机制 | 仍有效的机制说明；当前页数、模块数与输出文件以实际配置为准 |

v22保留在本目录，是因为其部门扩展与离线机制仍在使用。v23描述当前功能规划，v24描述当前呈现方式；它们承担不同职责，不能只按版本新旧互相替代。

## 按改动定位源码

| 改动对象 | 入口 | 维护提示 |
|---|---|---|
| 部门名称、输出文件、标题及布局选择 | [页面.json](../../看板/页面.json)、[页面配置.py](../../看板/页面配置.py) | 使用现有页面注册与输入校验机制 |
| 板块、卡片顺序、页面跨列 | [战略布局](../../看板/布局.csv)、[市场布局](../../看板/布局_市场部.csv)、[设计布局](../../看板/布局_设计部.csv)、[产品布局](../../看板/布局_产品部.csv)、[人力布局](../../看板/布局_人力部.csv) | 跨页引用复用同一模块，不复制业务数据 |
| 单卡标题、脚注、口径或绑定 | [模块目录](../../看板/模块/) | 保持模块ID、P号、来源与planned状态各自的含义 |
| 页面公共结构 | [看板骨架.html](../../看板/看板骨架.html) | 保留部门切换、单一片内目录及溯源控件契约 |
| 基础组件与当前UI | [基础样式](../../看板/_style.css)、[工作台样式](../../看板/_workspace.css) | 当前布局与设计令牌由工作台样式统一维护 |
| 本页模块检索 | [75_workspace.js](../../看板/渲染器/75_workspace.js) | 搜索负责定位，不筛掉模块，不改数据或P号含义 |
| 卡型渲染行为 | [渲染器目录](../../看板/渲染器/) | 注意按文件名顺序组合及跨组件依赖 |
| 生成页面与分享版 | [生成看板.py](../../看板/生成看板.py)、[打包单文件.py](../../看板/打包单文件.py) | 生成产物与普通页面共享来源配置，避免手改HTML派生产物 |
| 单位、频率、可靠度和来源 | [词条注册表](../../看板数据固化/词条注册表.csv)、[溯源表](../../看板数据固化/溯源表.csv)、[数据治理导航](../数据治理/README.md) | 元数据与来源不由部门布局重复维护 |

## 验收入口

以下为已有验收脚本的导航，本索引不表示它们已针对新的改动运行。

- [原看板浏览器回归](../../tests/verify_dashboard.cjs)：原有数据、预测、累计、公司切换、日期及媒体行为。
- [部门页面浏览器回归](../../tests/verify_department_dashboards.cjs)：页面复用、来源、规划卡、历史导航和离线分享。
- [工作台设计浏览器回归](../../tests/verify_workspace_design.cjs)：模块搜索、快捷键、输入法、隐藏公司定位及工作台布局。
- [分页与目录浏览器回归](../../tests/verify_interaction_navigation.cjs)：整卡原文、分页、真实滚轮/触摸、目录及离线版。
- [测试目录](../../tests/)：采集、迁移和数据规则的离线测试；改动范围涉及数据契约时一并查阅。
