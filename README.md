# DNS 市场与竞对监测数据看板

面向公司全员的数据看板项目：**109项监测源 · 上市公司五家切换面板 · 数值类固化CSV自动绑定 · 资讯类近7天自动更新 · 单文件HTML看板**。
覆盖宏观数据、大宗商品、行业数据、产品品类、竞对同业五大板块；竞对同业含安克/奥海/佳禾/海能/绿联五家上市公司切换面板（业绩/周转/主营构成/公告/互动）。
看板 v13 起**模块化**：一卡一配置（`看板/模块/*.json`）+ 布局表（`看板/布局.csv`）+ 渲染器组件库（`看板/渲染器/`）；
当前版本 **v26（资讯分页与可收缩目录）**：新闻、公告、问答、榜单及图文使用左右箭头分页，取消模块内部纵向滚动；新闻和图文整张条目可直接打开原文，首页图文精选同步使用直接链接。议息模块保留日程和决议说明，新增近30天官方资讯；战略页物流运价与航空货运需求并排。桌面目录可收成编号栏，窄屏使用可展开菜单。交互与验收见 [v26实施记录](docs/看板模块化/v26资讯分页与目录优化实施记录.md)；阅读、数值详情和搜索基础沿用v25/v24。

五部门继续共用98个已建模块与同一份数据，另有11个规划模块P255—P265。预留P号只保存在规划配置中，模块为planned、主数据为空，尚未登记实际来源或开展采集，不进入已接入统计。战略101卡（98已建+3规划）、市场53卡（51+2）、设计16卡（14+2）、产品31卡（28+3）、人力12卡（9+3）。全部内容限定外部公开情报；方案与编号清单见v23实施记录，部门复用机制见v22记录。

## 快速开始

**看数据**：双击打开 `看板/index.html`，点击页头右侧部门按钮切换视角，也可直接打开 `marketing.html`、`design.html`、`product.html`、`hr.html`（普通页面需与 `data.js`、`媒体/` 目录同目录；媒体目录由生成数据.py自动重建，勿手改）。手机上部门按钮自动分行显示。
发给同事用 `看板/数据看板-单文件版.html`（所有部门页面与数据已内嵌，单个文件即可离线切换、刷新和前进后退；图文照片内联，Amazon远程商品缩略图断网时可能不可见，榜单文字与价格保留）。
- 悬停图表查看历史各点数值；悬停卡片来源角标查看数据出处；页底附录为来源溯源索引。
- 本页搜索支持卡名、完整模块ID、真实数据P号及规划P号；`/`可聚焦（编辑文字时不抢键），Esc清空。结果仅定位，不隐藏卡片或筛除数据；点击后收起结果并激活目标公司。来源P号与模块文件数字ID分别检索，不从文件数字推断来源P号。
- 新闻、公告、问答、榜单及图文通过左右箭头翻页，滚轮与纵向触摸继续滚动主页面；新闻与图文点击整条即可在新标签打开原文，不再经过预览弹窗。
- 数值与说明卡底部可查看详情；趋势详情包含已保存完整历史、原始精度数据表与来源，表格每次加载50行。图文卡保留已有图片及摘要，待核对的配图仍显示“图片待核对”。数值详情可按Esc关闭，并回到原按钮。
- 左侧目录可收起，桌面保留编号与完整标题提示，内容区同步拓宽；窄屏点击“展开目录”选择板块，选中后自动收起。存储可用时记住收缩状态，受限时安全降级。
- “放大阅读”可进一步放大正文，手机页面的周期、来源与字号按钮分别排列。

**更新数据**（数据与页面分离，日常只重写 data.js，页面壳不动）：

```bash
# 方式一：双击 看板/更新看板.bat（采集+数据更新一键完成）

# 方式二：命令行
cd 看板数据固化/采集脚本
python run_all.py            # 全量采集（约5-8分钟），数值写 CSV数据/，资讯写 资讯数据/
python cross_check.py        # 行情双源交叉验证（可选）

cd ../../看板
python 生成数据.py           # CSV+资讯JSON → 重写 data.js（毫秒级，页面壳不变）
```

**调整看板本身**（v13模块化，详见 `docs/看板模块化/00_模块化设计与规范.md`）：

```bash
cd 看板
# 改卡片文案/脚注/绑定的P号 → 改 模块/对应.json
# 挪卡/加卡/删卡/调跨列   → 改 布局.csv（加删卡同步增删 模块/ 下JSON）
# 改某类卡的渲染行为      → 改 渲染器/对应.js
# 改单位/小数位/显示窗口/可靠度 → 改 ../看板数据固化/词条注册表.csv
python 生成看板.py           # 上述任何变更后重建页面壳（秒级、确定性）
```

发给同事前运行 `python 打包单文件.py` 生成最新单文件版。

**新增部门**：复制一份布局表，引用`模块/`里已有ID，在`页面.json`登记该部门，运行`生成看板.py`和`打包单文件.py`即可。新布局的“使用布局跨列”可设为true，使跨列只在本页生效；原模块文案、数据绑定和主看板布局均不改。详细字段与示例见v22实施记录。

**部署**：普通页面需上传`页面.json`登记的全部HTML（当前为`index.html`、`marketing.html`、`design.html`、`product.html`、`hr.html`），以及`data.js`和它引用的整个`媒体/`；仅上传index会导致部门链接失效。`媒体/`为本地生成且被Git忽略，推送Git不能替代CloudBase媒体发布。即便数值没有变化，重建`data.js`也可能引用新图片，发布前必须核对图片对象清单；验收不能只看HTTP 200，还需检查图片Content-Type、实际解码和引用路径（线上404兜底也可能返回200）。单文件版可单独发布，内含全部五部门视图与本地图文图片。部门页面用于筛选外部情报视角，共享客户端数据，不构成保密权限隔离。

调度建议：行情/资讯类每日（资讯采集器自动只保留最近7天）、宏观类每月发布后、季度类每季。
登录墙/JS渲染类条目（P07/P12/P28/P53/P70/P73/P76/P77/P83/P98/P99）走浏览器RPA，
提示词见 `看板数据固化/RPA数据/RPA任务提示词.md`，可直接粘贴到ZCode定时任务。

## 数据说明

- 每个CSV按 `板块-P序号-条目` 命名，第一列 `数据日期`，按日期行迭代（重复采集自动覆盖同日）
- 折线图显示窗口：月度宏观长历史默认近3年、日频行情默认近3个月（配置在 `词条注册表.csv` 的窗口列，经 `生成数据.py` 写入 data.js）；
  顶栏「周期」选择器可切换 3月/6月/1年/3年/全部，仅影响曲线渲染，CSV 保留全量历史
- 欧盟宏观（v11）：HICP/零售/德债/消费者信心经 Eurostat 官方 API 全历史回填（301~561个月）并图表化；
  欧元区PMI/德国IFO 为专有数据无免费结构化历史，保留最新读数卡
- PA/PC工程塑料（v11）：由生意社"商品报价动态"文章逐日考证回填（PC/PA6/PA66各400天）并图表化
- 穿戴/平板（v11）：按 IDC 新闻稿考证补齐缺失季度（见 行业历史考证-C.md）；平板2026Q3待IDC发布后补录
- Amazon榜单（v11）：CSV 增加商品图片URL列，看板 TOP5 图文展示（悬停可跳转商品页）
- 资讯标题（v11）：英文标题自动翻译为中文展示，悬停显示英文原题（翻译缓存于 资讯数据/翻译缓存.json）
- 多品类/多型号条目（芯片、存储颗粒、品牌份额）采用多数值列，一列一个品类
- 看板中每个数据卡片均标注来源与 `[P序号]`，可在页底「数据溯源索引」查到来源链接、采集方式与最近抓取日期
- 附录「最近数据」列（v17）：每词条最近数据日期，超过注册表频率阈值自动标注逾期（每日>4天/每周>10天/每月>40天/每季>110天/半年>200天/每年>380天），停更一眼可见
- 数值核验体系（v19）：落库前区间校验（注册表「合理区间」，越[拒]界拒写/越[疑]界告警）+突变检测；run_all 全量尾部自动跑12对双源对照；附录核验徽标（✓核验/⚠核验/⚠存疑）；周度抽查核对单（`python 采集脚本/生成_周度抽查.py`）。详见 docs/数据治理/07_数值核验体系_20261110.md
- 已回填历史的序列：ISM PMI、中国CPI/PPI同比+环比（东财数据中心）、美国CPI、PCE、美债、汇率、品类增速（统计局逐月考证）等；
  LME铜、布伦特、PVC/PP/锡/铝、沪金/沪银（期货主力回填）、手机/PC/平板/穿戴出货量与品牌份额（IDC/Counterpoint新闻稿考证，见考证文件）等
- 未固化或需RPA的词条及原因见 `固化说明.md`；考证文件（逐条数值出处）：`看板数据固化/` 下 `行业历史考证-C.md`、`物流存储考证-D.md`、`品类增速考证-E.md`
