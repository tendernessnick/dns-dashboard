# 拆解｜拆解报告：苹果新款70W USB-C氮化镓快充

继40W动态电源适配器之后，苹果进一步将 PD3.2 AVS协议引入大功率快充产品线，带来了全新的70W USB-C氮化镓快充。
相关阅读：苹果新款AVS充电器曝光，引领大功率快充生态普及
相较于上一代70W充电器，新款在插脚与接口设计上升级了新国标的包胶插脚，还将沿用多年的交流电源接口1全面换代为交流电源接口2，支持搭配新版电源适配器延长线和全球旅行转换器套件使用。
其次在快充协议上，新款在维持70W总功率不变的前提下，引入了PD3.2 SPR AVS协议，新增9.0-15.0V3.0A与15.0-20.0V3.4A两段AVS动态调压档位，弥补了老款70W缺失AVS协议的短板。
充电头网评测室实测可顺利触发iPhone 18 Pro系列50W以上的满血AVS快充，仅需15分钟即可为iPhone 18 Pro Max充至50%电量。

下面充电头网就带来这款产品的详细拆解，一起来看看内部的设计和用料如何。
包装盒延续苹果经典的极简白色方盒设计风格，正面左上角印有苹果logo和70W Power Adapter产品名称，中心区域印有充电器本体的渲染图。
包装盒背面顶部设有带有苹果经典的易撕拉封条，右上角特写标注交流电源接口2示意图，提示用户该产品采用了新一代交流电源接口。
打开包装，内部包含苹果新款70W电源适配器本体、说明书与安全信息手册。输入延长线和快充线则需用户单独购买。
苹果新款70W充电器延续了家族标志性的豆腐块造型，通体采用白色高光亮面PC阻燃材质外壳，四周边角过渡圆润，机身正背面中心均设有经典的凹印苹果logo，极具辨识度。
充电器整体外观风格与苹果历代MacBook电源适配器一脉相承，一端配备可折叠国标插脚，另一端配置单USB-C输出接口，收纳时不易刮蹭包内同行物品。
机身输出端居中偏上位置配备单USB-C接口，采用白色胶芯。
交流输入端配备可折叠新国标插脚，插脚收纳后尖端略凸出机身外框，方便用户日常单手拨出使用。
机身底部采用镭雕印有产品参数铭牌。

型号：A3543
输入：100-240V~ 1.8A 50-60Hz
输出（USB PD）：5.0V3.0A 或 (AVS) 9.0-15.0V3.0A 或 (AVS) 15.0-20.0V3.4A 或 20.6V3.4A
制造商：赛尔康技术（深圳）有限公司
充电器已通过3C、KC、BSMI、SAFETY MARK、PSE、ISC认证以及VI级能效认证。
插脚模块延续了苹果一贯的可拆卸更换设计，取下插脚模块后，机身可搭配苹果官网在售的交流电源接口2电源适配器延长线或全球旅行转换器套件，适应远距离取电或跨国差旅场景。
去掉插脚模块后，内凹区域采用浅灰色外壳撞色设计，上方设有一颗圆形金属T型固定座，在连接三脚交流电源延长线时还可充当接地使用。
交流电源接口2母座内部为跑道型凹槽结构，内设两根镀镍圆头交流输入插针，凹槽上方印有充电器序列号F16HXA006220001G3Q。
独立可拆卸插脚模块特写，新款插脚新增了白色绝缘包胶设计，符合新国标规范。
插脚模块内侧设有U型导向滑槽。
插脚模块型号为A3612，支持250V~ 2.5A规格，由捷普生产制造。

通过对PCBA模块的整体观察可见，苹果新款70W氮化镓快充采用反激开关电源架构，初级由苹果定制控制器搭配纳微氮化镓功率芯片，次级采用同步整流，并由英飞凌协议芯片控制实现PD3.2及SPR AVS输出。
下面我们就从输入端开始逐一解析各个元器件的信息。
输入端延时保险丝特写，套有热缩管绝缘。
安规X2电容来自TDK，用于滤除电网输入端的差模电磁干扰。
两级共模电感均集成固定在定制的黑色塑料绝缘骨架上，第一级共模电感采用扁平铜带绕制，绕线紧密整齐。
塑料骨架另一侧的凹槽内嵌有第二级共模电感，采用铜线和漆包线并绕设计。
整流桥外贴有金属散热片。
拆下的整流桥正面特写，表面无丝印。
一颗差模工字电感特写，外包热缩管绝缘。
五颗高压滤波电解电容外观包裹了一层全黑热缩管。
剥开最右侧电容外层的热缩管，可见高压滤波电容来自CapXon丰宾，单颗规格为400V 22μF。
另外还有一颗丰宾同规格高压滤波电容，可见初级侧共计六颗同规格高压滤波电容。
为初级主控芯片供电的滤波电解电容外部同样套有一层黑色热缩管。
去除外层黑色热缩管，可见这颗电容来自Lelon立隆。
焊接在PCB正面的初级主控芯片特写，这是苹果深度定制的开关电源控制器，表面丝印APSLCA01，在苹果多款氮化镓快充产品中均有广泛应用。
产品内置的初级开关管来自Navitas纳微半导体，型号为NV6017C，采用PQFN 5*6封装，导阻120mΩ，芯片内置氮化镓功率器件与驱动电路，外围元件更加精简。
一颗高压MOS管来自ST意法半导体，丝印65PF6，采用PowerFLAT 5*6封装。
另一颗高压MOS管来自AOS万国半导体，实际型号为AONS660A70F，是一颗耐压高达800V的NMOS管，导阻550mΩ，采用DFN 5*6F封装。

产品内置的快充协议芯片来自Infineon英飞凌，型号为CYPDC1185B2-32E，属于英飞凌EZ-PD CCG3PA系列控制器，内置32位Arm Cortex-M0处理器，采用32-pin QFN封装。相较于上一代70W充电器搭载的CYPDC1185B2-32D，新款升级为“-32E”版本（与苹果40W AVS动态快充同款），不仅原生支持最新的USB PD3.2快充标准与9-20V SPR AVS动态调压协议，还集成了系统级过压、过流、欠压、过热保护以及CC/SBU/VCONN引脚对VBUS短路保护功能。
输出VBUS开关管来自AOS万国半导体，型号为AON7428，是一颗耐压30V的NMOS管，导阻低至2.3mΩ，采用DFN3.3*3.3封装。

苹果新款70W USB-C氮化镓电源适配器在外观上延续了苹果家族标志性的豆腐块造型，并引入了PD3.2 SPR AVS快充协议。实测为MacBook Pro 16充电功率可达67W+，为iPhone 18 Pro Max充电最高功率可达52W+，补齐了旧款70W充电器不支持AVS协议的短板。
充电头网通过拆解了解到，苹果新款70W氮化镓充电器由赛尔康代工生产，内部延续了苹果原厂电源一贯的严苛设计标准。
电路架构方面，初级侧采用苹果定制主控芯片APSLCA01，初级开关管选用纳微NV6017C氮化镓功率芯片，并搭配意法半导体65PF6N2与万国AONS660A70F两颗高压MOS管；次级侧采用丝印D9 6ZZ的同步整流控制器搭配丽正RM85N100DF同步整流管。
输出端则选用英飞凌CYPDC1185B2-32E快充协议芯片搭配万国AON7428 VBUS开关管，实现最高70W输出。
在电容选型方面，初级采用六颗丰宾400V 22μF电解电容与立隆供电电容，次级采用两颗尼吉康与一颗丰宾共三颗固态电容用于输出滤波。
此外，产品内部还通过定制塑料骨架将共模电感、平面变压器与电容分区隔离支撑，并在PCBA正背面配备了定制硅胶垫。两侧外壳内还铺设了大面积石墨层导热贴纸。整体做工扎实、散热稳健，充分展现了苹果一贯以来的设计理念。
