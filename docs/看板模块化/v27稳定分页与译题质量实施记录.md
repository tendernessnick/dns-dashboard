# v27 稳定分页与译题质量

日期：2026-11-13。

用户反馈：议息等模块会随当前页条目数量改变高度，翻页后页面跳动；中文新闻标题存在不自然和数量级误译。本次统一修正同类模块与标题处理链路，不修改原始数值口径。

## 阅读区域稳定

`04_pager.js`与`_pagination.css`按卡型、容器宽度及字号确定阅读槽位，不根据当前页实际内容量测高度。普通资讯每页3条，窄卡2条；榜单使用独立槽高；图文宽卡并排2张、窄卡1张；议息资讯使用2个紧凑槽位。手机和放大阅读可以主动重排，但重排后的翻页、图片加载、末页不足及0条均保持稳定。

只渲染真实消息，不为填满区域虚构条目；没有消息时由唯一空态显示“暂无新消息”，真实条数为0。单页和空态均保留44px按钮区域并禁用无效箭头，避免按钮消失造成高度变化。日历失败说明也预留固定一行，成功时不输出假状态文字。

标题、摘要与参数按固定槽位适度截行，完整文本及原题保留在DOM和悬停提示，原文链接保持可用。没有重新引入内部纵向滚动；鼠标滚轮和竖向触摸继续作用于主页面。打印时恢复完整内容排版。

## 通用译题质量层

`采集脚本/_news_translation.py`仅依赖标准库，提供纯离线规范化与质检；采集端及数据导出端共用，生成器不导入网络采集模块，也不发翻译请求。

- 原英文`title`、链接、日期和原始资讯文件只读保留。展示增加`title_display`、`translation_status`及`title_translation`元信息，不用中文覆盖原题。
- 统一HTML实体与空格，保护金融/科技术语、品牌、金额和计量单位；使用精确数量指纹核对百分比、币种、数量级、正负和单位，允许等值中文数量表达。
- 缩写允许正确中文等价表达，例如CEO/首席执行官、AI/人工智能、ECB/欧洲央行及季度，不强制把合格中文改成英文缩写。
- 对公开服务的HTTP、Content-Type、业务状态、返回结构、配额报文及保护标记做校验；服务错误和失败译文不作为永久成功缓存。
- 增加可复现的常见退化护栏：数字孤立接连接词、财报“非常强烈”、波动误译成单边涨幅、货币政策理事会误译董事会、航空premium误译金融溢价、回应担忧被强化为已经消除，以及不完整或年份倒挂的中文日期。
- 规则包含上下文约束，不全局替换premium或Board；无法可靠接受的新译题回退合格旧译，再不合格则展示原题并标“待校译”。质检不是新闻事实核验，元信息明确`fact_verified=false`。

版本化正缓存绑定术语规则与原题哈希。`_news_common.py`保留旧`translate_title(title, cache)`接口，并提供默认离线的结构化接口。原平面缓存仍兼容，只有新版本且通过复查的正缓存可直接复用；缺失或失败不会因旧空缓存永远不重试。

`生成_译题候选.py`默认离线，只输出候选到新的审查文件，禁止覆盖原资讯、图文、CSV或已有缓存；显式`--allow-network`才可对公开标题调用现有翻译端点。生产导出读取独立的`资讯数据/标题翻译校验缓存.json`，不修改旧采集存档。

本轮对22条现有英文标题进行候选重译和规则复查；退化的新候选保留合格旧译，官方已校译标题继续保留。1条“biggest moves”标题按原题另作校译并明确记录`assistant_reviewed`，没有在代码中硬编码整句标题映射。例如原“超过1万$”改为“超过1万亿美元”，不将“波动最大”偷换成“涨幅最大”。新规则适用于后续采集，并不保证能自动识别所有语义错误。

## 构建保护

当前默认conda Python缺少Pillow，旧图片函数会吞掉ImportError并导出空图片。生成器现于任何数据写入、媒体清理之前验证Pillow，缺依赖明确停止并保留旧版本。已用依赖完整的环境重建，恢复36个本地图文图片引用及离线嵌入；没有发布缺图中间版本。

## 验证与范围
