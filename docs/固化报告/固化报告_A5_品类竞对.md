## 三、实现要点与源变更说明

1. **P56**：WPC 官方 API `jpsapi.wirelesspowerconsortium.com/ajax/products/qi` 一次返回全库 JSON 数组（12,012 条），本地统计 Qi2（功率档 MPP 开头或版本 2.x），并附本月新增认证数于备注。
2. **P58**：任务给的 NAND 路径 `/price/nand/nand_spot` **已 404**，实测改用 `/price/flash/flash_spot`（已在脚本与 CSV 备注注明）。取各行"Session Average"（行内 `</tr>` 截断防串行）。
3. **P68/P72/P92（Amazon）**：requests 直连可解析（zgbs 页 data-asin 卡片切片：排名 zg-bdg-text / 标题 img alt / 价格卡内 `$xx.xx`）。P92 必须先访问榜单页建立会话 cookie 再开详情页。P72 原线材节点 16676470011 已失效（页面"Best undefined"无商品），脚本按 回退链（旧节点→21209107011 线材→2407761011 充电器）实抓，本次命中现行"Cell Phone Cables & Adapters"节点，CSV 备注记录实际节点。
4. **P79/P80**：pymupdf 解析本地年报 PDF（`抓取测试/anker_ar2025.pdf`，238页），正则锚定"充电储能类"分产品行与前五名客户合计行；脚本校验文件为 2025 年报，换年报需同步更新。
5. **P82**：新浪财务指标页 GB2312，解析表头报告期与值列对齐；口径取**最新年报期(12-31)**（当前=2025-12-31），避免与季报期累计周转率直接对比失真（已在备注说明）。
6. **P84**：POST `irm.cninfo.com.cn/newircs/index/search`（common.http_post 自带 X-Requested-With），问答条数=contentType 1（投资者提问），公告类(3)不计入但命中数写入备注。
7. **P93**：Kickstarter 页面被 Cloudflare 拦截（requests 403），改用 **curl_cffi(chrome 指纹)** 调 discover JSON 接口 `?category_id=16&sort=magic&format=json`；Top1 取首个 live 项目，热门榜为实时排序，与前次实测项目不同属正常。
8. **P94**：摩点首页 HTML 内嵌"24小时热度榜"，正则取第一个 `pc_ga_rank_{id}` 块的标题与 backer_money（UTF-8 强制解码）。
9. **P95**：深圳局列表 AJAX 为 **GET** `www.csrc.gov.cn/searchList/{channelId}?_isJson=true&page=1`（channelId=26d8295b…，与 common_list.js 一致；POST /searchList 现返回 HTML 兜底页）。列表倒序，第 1 条即最新。官网站时不稳定，脚本内置 5 次多指纹重试；本次运行中曾失败 2 次后成功，最终状态成功。
10. **P95 数据口径提示**：该栏目 total=363，最新公告为 2021-09-30（正浩创新/EcoFlow 备案）。深圳局 2021-09 后辅导公示未再入该栏目（新备案改走其他公开渠道），如需跟踪新备案需另找数据源——本批次按任务定义固化该栏目口径。
