## 四、登记的机制性发现（后续运维须知）

1. **东财 push2/push2his 渐进式限流**：单 IP 每 2~3 分钟窗约 2~4 次成功配额，超限先截断响应（~160字符）后断连，冷却恢复；`92.push2his` 编号镜像不可用；datacenter/emweb/searchapi 不受限流影响。偶发"GET失败"属正常波动，重试/冷却即可，**不要在失败后立即密集重试**（会延长封锁）。
2. **桌面系统代理**：开启时东财直连质量进一步下降；common 已显式直连（trust_env=False）免疫。
3. **样本外推警示**：当日限流致 K3 两项抽样（布伦特 B00Y 数值、112.LMC 存在性）三次窗口均未能完成——P36/P26 维持观察项，待下次例行更新后的低负载窗口补测（对照值已存档 02 报告）。
