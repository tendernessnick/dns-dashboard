# 数据看板"数据溯源标注"设计研究

> 目标：为单文件 HTML 数据看板（94 个数据词条）设计一套专业、可追溯、不打扰浏览的数据出处标注体系。
> 研究日期：2026-10-23。方法：WebSearch / WebFetch 检索业界产品与设计模式文献。

---

## 一、业界做法调研

### 1. Bloomberg Terminal（彭博终端）
终端每屏数据以屏幕底部 Caption 行与 "Source: Bloomberg" 式脚注标明出处；指数类数据进一步细化到子服务，如官方方法论文件写明 "Source: Bloomberg's evaluated pricing service (BVAL)"。机构引用时的标准格式是 "Source: Bloomberg unless otherwise noted"（来源为彭博，除另有注明外），并附商标声明。外部转载终端截图受条款严格限制，体现"出处标注即合规要求"的思路。**启示：来源行是默认配置而非可选装饰；对聚合数据要标注到最上游子来源。**

### 2. 券商研报（广发证券、交银国际、浦银国际等，基于 Wind / Choice / iFinD）
每张图表下方固定一行小字："数据来源：Wind，同花顺官网，Bloomberg 官网，东方财富Choice 公众号，公司年报，广发证券发展研究中心"——多个来源并列、以逗号分隔、注明机构与加工方， Wind 导出图表自带右下角水印。**启示：图表级来源行是最被金融从业者接受的形态；标注粒度 = 原始来源 + 加工方。**

### 3. 国家统计局 / 国际组织统计出版物（UN、IMF、UNESCAP）
官方统计手册采用逐条编号注释，如"中国耕地面积数据来源于中华人民共和国国土资源部""中华人民共和国国家统计局，《中国统计年鉴》，2012 年"，集中列于表格下方或文末。UNESCAP 报告示例"数据来源：经合组织（2018 年 9 月 8 日查阅）"——**带查阅/抓取日期**。IMF SDDS 标准要求公开数据来源与编制方法。**启示：溯源四要素 = 来源机构 + 具体出版物/URL + 查询日期 + 编制方法。**

### 4. FRED（圣路易斯联储经济数据库）
每张图下方提供 "Cite" 标签页与 "Notes" 注释区，标准引用格式为：序列标题 + 原始来源机构（如 BLS）+ "retrieved from FRED, Federal Reserve Bank of St. Louis" + 系列 URL。明确要求聚合平台用户**引用原始来源而非仅引用 FRED**。**启示：中间采集层与原始来源分开标注，即"来源链"概念。**

### 5. Our World in Data（OWID）
每张图表左下方固定一个 "Source" 链接，点击跳转到原始数据来源页；页面底部另有 "How to cite this page" 引用块（作者、年份、标题、URL 齐全）。**启示：图表下方放一个轻量来源链接即可，完整引用信息收进页面级附录，两层互补。**

### 6. 学术出版物（Vancouver / AMA 数字上标引用制）
正文按首次出现顺序编上标数字（¹ ² ³，连续引用合并为 ¹⁻³），文末对应编号列出完整参考文献列表。**启示：上标序号 + 文末索引是处理"大量出处"最紧凑、最严肃的成熟方案，94 条数据正适合此模式。**

### 7. Dashboard Design Patterns（Bach 等，2023，模式库）
将 "Data source" 归入仪表盘"元信息（Meta Information）"模式组：标明数据来自哪里，可附链接、采集与分析方法、所用工具；配套模式还有 Disclaimer（数据局限说明）、Update information（最后更新时间）、Data description（数据口径描述）。建议来源标注可点击外链、并内嵌原始数据表供核对。**启示：溯源应成组出现——来源 + 更新时间 + 口径说明是一个"元信息包"。**

### 8. Visualization Badges（VIS 2025 论文）
研究提出在可视化旁放置图形化"徽章（badge）"传达数据出处与设计决策：小图标/短标签占位极小，悬停或点击展开细节。**启示：徽章 + 悬停展开是"严肃可见但不打扰"的关键交互形态。**

## 二、推荐方案：三层溯源体系

总体原则：**注册表驱动（一处定义，处处引用）、序号制（Vancouver 式）、渐进披露（先角标 → 再悬停 → 再附录）**。

### 2.0 数据模型：双层注册表

94 个词条可能大量复用同一来源网站，因此拆成两层，避免 URL 重复维护：

```js
// ① 来源站注册表（去重后约 10~30 个站点）
const SOURCES = {
  stats:  { name: "国家统计局", url: "https://www.stats.gov.cn/", org: "中华人民共和国国家统计局" },
  pbc:    { name: "中国人民银行", url: "http://www.pbc.gov.cn/" },
  wind:   { name: "Wind", url: "https://www.wind.com.cn/" },
  // ...
};

// ② 词条溯源注册表：94 行，与卡片一一对应（单一事实来源）
const PROVENANCE = [
  {
    id: "P01",                 // 词条编号 = 序号上标 + 附录行锚点
    title: "GDP 当季同比",
    source: "stats",           // → SOURCES 键
    url: "https://…",          // 具体数据页 URL（深链）
    method: "curl+解析HTML",   // 采集方式：curl / API / 手工录入
    freq: "季",                // 更新频率
    lastFetch: "2026-10-22",   // 最近抓取/查阅日期（UNESCAP 规范）
    status: "ok",              // ok | stale | failed
    note: "经 XLSX 二次整理",  // 可选：加工说明（来源链第二级）
  },
  // …共 94 条
];
```

### 2.1 第一层：卡片级标注（每个词条卡片底部）

**形态**：卡片底部一条 11–12px 灰色（#6b7280）小字来源行，上方以 1px 淡色发丝线与正文隔开，结构为：

```
───────────────────────────────
来源 国家统计局 [P01] · 季更 · 10-22 抓取  ●正常   ⧉
```

- **来源名**：可点击，悬停出 tooltip（见 2.4），点击滚动到附录对应行并高亮。
- **`[P01]` 序号角标**：等宽数字、上标或方括号样式， Vancouver 式全局唯一编号；点击同上跳附录。
- **频率 + 抓取日期**：日期只写 `MM-DD` 省年份（当年数据），完整日期入附录——控制卡片信息密度。
- **状态点 ●**：绿=正常 / 琥珀=滞后 / 红=失败，8px 圆点，`title` 提示，颜色同时编码进附录。
- **外链图标 ⧉**：直接新标签打开来源 URL（深链），悬停显示完整地址。
- **位置与视觉权重**：置于卡片 footer、右对齐或左对齐统一即可；整体不超过卡片高度 12%，浏览时"扫得到但不抢戏"。

### 2.2 第二层：图表级标注

图容器左下角固定 caption（研报惯例）：`来源：国家统计局 [P07]；数据截至 2026-09`。若一张图聚合多个词条，写成 `来源：Wind [P12]、统计局 [P07]`，多个序号并列（对应学术引用 ¹⁻³ 的合并写法）。图表 caption 与卡片来源行重复时，图表内可省略，仅保留序号。

### 2.3 第三层：全局溯源索引表（附录）

**位置**：页面最末独立区块，标题"附录 · 数据溯源索引"，**默认折叠**，收起态显示摘要条：

> 数据溯源索引（共 94 条 · 覆盖 14 个来源 · 3 条待修复）▸ 点击展开

**表列结构**（一词条一行，共 94 行）：

| 列 | 说明 |
|---|---|
| 序号 | P01…P94，锚点 id=`prov-P01`，hover 行高亮 |
| 数据词条 | 名称，点击回跳看板卡片（id=`card-P01`），形成双向跳转 |
| 来源网站 | SOURCES 注册表渲染，可点击外链 |
| 来源 URL | 截断显示域名+路径，`⧉` 打开、`⧉复制`入剪贴板 |
| 采集方式 | curl / API / 手工，用小徽章（badge）样式 |
| 更新频率 | 日/周/月/季 |
| 最近抓取 | YYYY-MM-DD 完整日期 |
| 状态 | ●正常/滞后/失败（与卡片状态点同色） |

**功能**：
- **筛选**：表头上方三个下拉（来源网站 / 采集方式 / 状态）+ 一个关键词搜索框（匹配词条名与 URL）。94 行数据无需分页，单页滚动即可。
- **排序**：点击表头按该列排序（序号/抓取日期/状态最常用），纯 JS 实现。
- **折叠/弹层二选一**：推荐折叠区块（打印时 `@media print` 自动展开、隐藏筛选器）；若看板为全屏大屏模式，可提供"溯源"按钮弹出右侧抽屉（drawer）承载同一张表。
- 顶部图例说明状态色与"抓取"含义（例：`抓取 = 最近一次成功拉取源站数据的日期`）。

### 2.4 悬浮 tooltip：来源详情交互细节

复用一个全局 tooltip 节点（性能好、样式统一）：

- **触发**：mouseenter/focus 在来源名或 `[P01]` 角标上，**延迟 150ms** 出现避免扫过时闪烁；mouseleave/blur 即隐。
- **内容**（即"元信息包"，对应 Dashboard Patterns 的成组建议）：

```
GDP 当季同比 · P01
来源    国家统计局
链接    https://…（可点击、可复制）
采集    curl + 解析HTML
频率    季更    上次抓取 2026-10-22
状态    ● 正常
备注    经 XLSX 二次整理
```

- **行为**：鼠标可移入 tooltip 内不消失（300ms 宽限期），便于复制链接；边缘自动翻转防溢出；Esc / 点击外部关闭。
- **可达性**：角标 `tabindex="0"` + `role="button"` + `aria-describedby`，键盘 Tab 聚焦即显示。
- **移动端**（媒体查询）：悬停不可用 → 点击角标弹出底部弹层（bottom sheet），内容同 tooltip。
- 角标与附录行是同一数据的两个入口：tooltip 管"快速看"，附录表管"逐条核对与筛选"。

### 2.5 与"严肃美观"的平衡清单

1. 页面页脚固定一行总声明：`数据来源：见附录数据溯源索引；数据仅用于内部研究，转载需注明原始来源。`（研报 + Bloomberg 惯例）
2. 抓取日期必须出现（UN 规范"来源 + 查阅日期"），这是可追溯性的最小闭环。
3. 序号制而非在卡片上堆 URL：URL 全部收进附录/tooltip，卡片视觉零噪音。
4. 状态色仅用于 8px 圆点与表内徽章，不整卡染色，避免告警感污染整体风格。
5. 支持深色模式：来源行用 CSS 变量（`--muted`），勿写死灰色。

## 三、落地实现要点（纯前端单文件）

### 3.1 组织方式

1. **唯一数据源**：`PROVENANCE` + `SOURCES` 两个 JS 常量放 `<script>` 顶部（或 `<script type="application/json" id="prov-data">` 内嵌 JSON，便于日后由采集脚本整表替换）。**卡片 HTML 不手写来源信息**，由 JS 渲染时注入，保证卡片角标、tooltip、附录表三处永不失同步。
2. **渲染时机**：`DOMContentLoaded` 后遍历 `PROVENANCE`：
   - 为每张卡片 footer 注入来源行（按 `id` 匹配 `data-prov="P01"` 容器）；
   - 一次性生成附录 `<tbody>`（94 行字符串拼接后 `innerHTML`，性能无忧）；
   - 绑定 tooltip 委托事件（`document.addEventListener('mouseover')` + `closest('[data-prov-ref]')`，94 个元素只需 1 个监听器）。
3. **锚点双向跳转**：
   - 卡片容器 `id="card-P01"`，附录行 `id="prov-P01"`；
   - 跳转函数：`document.getElementById(id).scrollIntoView({behavior:'smooth', block:'center'})` + 瞬时添加 `.flash` 类（2s 背景渐隐动画），不依赖 `:target` 以免污染历史栈；
   - 返回用 `history.replaceState` 记录原滚动位置或直接再跳回 `card-P01`。

### 3.2 关键 HTML 结构

```html
<!-- 卡片来源行（JS注入） -->
<footer class="card-src">
  <span class="src-dot" data-status="ok" title="抓取正常"></span>
  <span class="src-name" data-prov-ref="P01">国家统计局</span>
  <sup class="src-ref" data-prov-ref="P01">[P01]</sup>
  <span class="src-meta">季更 · 10-22</span>
  <a class="src-link" href="…" target="_blank" rel="noopener" title="打开来源页">⧉</a>
</footer>

<!-- 全局tooltip（复用单节点） -->
<div id="prov-tip" class="prov-tip" role="tooltip" hidden>…</div>

<!-- 附录：默认折叠 -->
<section id="provenance-appendix" class="appendix" data-open="false">
  <button class="appendix-toggle">数据溯源索引（94 条 · 14 个来源 · 3 条待修复）</button>
  <div class="appendix-tools">
    <select id="f-source">…</select><select id="f-method">…</select>
    <select id="f-status">…</select><input id="f-q" placeholder="搜索词条/URL">
  </div>
  <table class="prov-table">
    <thead><tr>
      <th data-sort="id">序号</th><th data-sort="title">词条</th>
      <th>来源网站</th><th>来源URL</th><th data-sort="method">采集方式</th>
      <th data-sort="freq">频率</th><th data-sort="lastFetch">最近抓取</th>
      <th data-sort="status">状态</th>
    </tr></thead>
    <tbody><!-- JS生成 94 行 --></tbody>
  </table>
</section>
```

### 3.4 质量自检要点

- 卡片 `data-prov` 与 `PROVENANCE[].id` 一一对应，JS 初始化时校验数量 = 94，缺漏在控制台告警；
- 所有外链 `target="_blank" rel="noopener"`；
- tooltip 内容与附录行共用同一渲染函数 `renderProvDetail(p)`，单一实现；
- 打印/导出 PDF 时附录自动展开且带页码分隔。
