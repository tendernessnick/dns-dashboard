# v25 阅读与详情 · 实施记录

日期：2026-11-12。

本版在v24五部门工作台基础上改善阅读与查看依据的路径：首屏突出当前已有资料，正文与按钮更易辨认，卡片通过明确入口展开历史、图文或来源。沿用外部公开情报范围，不新增采集，也不生成AI判断、虚构销量或未保存的正文。

## 一、阅读与首屏

### 字号、颜色与操作

整体保持柔和浅底、深色文字，使用克制的蓝绿强调操作和选中状态。中文标题与用途说明优先，弱化英文眉标。主要正文为15—16px、卡片标题17px、图表坐标与注释至少12px；辅助来源、状态与日期维持清楚的层级。

详情入口、图文预览、公司切换、关闭等主要按钮提供至少44px的点击高度。工具条新增“放大阅读”，可主动切换更大的卡题、正文与说明；切换后重绘可见图表，按钮状态通过`aria-pressed`表达。字号开关只影响本页呈现，不改数据和统计口径。

页面标题下的“数据范围与说明”改为原生折叠区，保留来源词条、已建模块与规划预留的真实数量，减少首屏对解释性信息的占用。“已建”仍包含原有受限模块，不等于全部已接入。

### 每页三个精选入口

精选由现有模块与同一份载荷生成，不另建业务模块，也不新增数据绑定。数值显示自身有效观测期，图文和榜单显示已有资料日期；不能把“全库最新观测”当作每项数据都更新到该日。

| 页面 | 精选内容 | 复用模块与边界 |
|---|---|---|
| 战略 | 伦铜、美元兑人民币、通讯器材零售 | P26、P21、P71；保留合约、人民币中间价及广义零售口径。 |
| 市场 | 终端新品、线材榜单、充电产品拆解 | 42、66、90模块；榜单是商品样本，不代表实际销量。 |
| 设计 | 产品拆解、音频评测、终端新品 | 90、91、42模块；第三方评测不等于全部用户反馈。 |
| 产品 | 终端新品、手机配件榜单、全球手机出货 | 42、68、44模块；商品排名不等于销量，终端出货不等于配件需求。 |
| 人力 | 同行招聘入口、公开项目公告、业务问答 | 83、81、84模块；职位明细尚未接入，公告不直接证明招聘或扩张计划。 |

数值精选通过显式P号进入对应指标详情。例如美元兑人民币精选只展开P21，不一次展示汇率横条的全部指标；原汇率卡的整卡详情仍可查看其全部真实依赖。图文精选进入已保存的具体条目，榜单精选进入当前样本。

## 三、卡片点击与具体内容

卡片底部增加明确的详情按钮，原来的图表滑动查值、公司切换和来源外链保持各自职责。避免整卡覆盖式点击与图表触控、原文跳转相互冲突。

| 卡型 | 展开内容 | 限制 |
|---|---|---|
| 趋势、多列指标 | 更大的历史图、序列选择、日期跨度、载荷中的完整历史表及口径来源 | 不新增财务比较，不混淆主指标单位与其他列。 |
| 新闻与图文 | 已保存标题、日期、摘要、标签、图片及独立原文链接 | 无摘要时如实提示；不拼写未保存正文，不根据摘要作新判断。 |
| 竞品榜单 | 当前载荷中的商品排名、标题、价格、快照日期及商品链接 | TOPS当前只保存前5项商品详情，完整样本总数另列；不能声称已展示全部30件商品详情，不能补造历史或销量。 |
| 规划卡 | 用途、计划内容、展示字段、候选来源和使用边界 | 持续显示“规划中、尚未接入数据”。 |
| 无P号或受限说明卡 | 已有说明与可用的外部查询入口 | 不因可打开详情就变成已接入，不生成占位数值。 |

图文卡使用独立预览按钮和原文链接，交互元素不相互嵌套。预览显示已有大图与摘要，原文在新标签打开。若标题或正文在生成载荷时已被截短，详情只能展示当前保存内容，不补全缺失部分。

### 手机品牌份额

主页P49改为**最新观测期的横向排行**：以100%为统一长度基准，按本期份额排序，并显示实际观测日期。零值保留，缺失值单独表达，不自动补零，不把当前排序解释为排名变化或销量变化。

原有历史季度记录仍在DDATA中，通过详情表查看。`49_手机品牌份额多季度.json`仅调整卡名与标题提示来对应新图形口径，不改模块ID、P49绑定或历史数据。

## 四、统一详情层

### 原生弹窗与焦点

`80_details.js`通过纯DOM创建唯一原生`dialog#moduleDetail`，挂在`#dns-dash`内。桌面以右侧详情面板呈现，手机使用全屏空间；正文独立滚动，关闭按钮始终明确。

- `showModal()`提供背景inert与原生Esc取消；同时动态维护Tab与Shift+Tab的首尾循环，防止焦点离开详情。
- 可用焦点包括按钮、有效链接、输入和选择控件、原生summary以及可键盘滚动的表格区域；隐藏、禁用和折叠详情内的不可见控件不参与循环。
- 关闭后回到触发按钮；若触发按钮或所属卡片已不可见，则回到搜索框或安全的可见入口。
- 最后一批历史加载完成后，若“加载更多”按钮将隐藏，焦点转到表格区域，避免掉到页面body。
- `75_workspace.js`在有打开的dialog时不处理搜索快捷键；详情内的`/`不触及背后搜索，Esc继续关闭当前弹窗。
- 不克隆包含`data-mid`、`data-k`或业务ID的整卡，避免重复ID和详情内容被当作第二张业务卡。

### 只读数据与完整历史

详情只读取DDATA、BIND、META、REVIEWS、TOPS、NEWS和PROV。显式P号入口必须命中本页卡片的真实`data-k`或`data-source-pids`，不从模块数字推造P号。

图表使用`drawChart(el, redraw, seriesOverride)`的独立序列入口，按选中列过滤有限数值，展示**已保存的完整有效历史**。它不受主页WIN/PSEL窗口截取，也不改写这些全局设置；缺失值不补点。主页原调用方式保留。

多列图的查值说明使用实际字段名称，不把BIND中的主指标单位套到所有列。累计与预测继续继承原卡的`data-change`、`data-trend`等限制，预测不连接成历史趋势，不新增无效环比或财务推导。

历史表展示当前载荷中保留的日期与字段，按由新到旧排列；初次50行、每次再加载50行，标题明确总行数和当前显示数。零值保留，null、空字符串及缺失单元格显示“—”；数值使用原始字符串，不额外换算。这里的“完整历史”限定为当前载荷，不能代指源CSV未导出的文本列或源站全部历史。

### 来源、安全与信息层级

只有存在内容的分区才显示，不为每张卡建立一组空标签页。图文和榜单优先呈现资料；来源、口径及核验放在后面。来源机构与META口径正常显示，较长的采集方式和来源备注放入“采集与核验说明”折叠区，标明其记录属性。

结果正文采用`textContent`和DOM创建，不把查询、标题或摘要作为HTML执行。外链仅允许http/https，并设置noopener；图片只接受受控本地媒体路径、允许的data:image编码和http/https，拒绝javascript与data:text。TOPS已在生成端转义的标题和图片URL只还原一次，再经过文本输出或URL白名单；REVIEWS原始字符串不重复解码。

### 配图核对

本地P90有五篇不同文章保存了相同内容的图片，视觉检查确认是重复头像。构建器按同一P目录内图片文件的SHA-256分组，将重复配图路径写入MEDIA_OMISSIONS；70/78/80统一不展示这些图片并标明“图片待核对”。原始图片和数据载荷保留，不联网补图、不生成替代图。单文件打包时名单路径和业务图片一同转换为内嵌URI，因此两种交付保持相同处理。精选优先采用已有可用图片与摘要的条目，按钮指向其真实索引。

名单按当前本地媒体生成；采集配图修正并重建媒体后，需重新生成页面与分享版。相同图片不直接被判定为内容错误，仅在确认前不作产品图片放大展示。
