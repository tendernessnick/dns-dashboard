## 任务一：P93 Kickstarter 众筹热门快照

**背景**：Kickstarter 对数据中心流量启用了 Cloudflare 拦截（curl_cffi 间歇 403），真人浏览器可正常访问。

【锚点校验】落盘目录必须已存在；若不存在请先在资源管理器创建，勿自行改名。

- 打开 `https://www.kickstarter.com/discover/categories/technology`（Discover → Technology，按 Most Funded 排序）
- 取前 12 个项目，逐条记录：排名、项目名、众筹金额（USD，去千分位）、支持人数、完成度%（如有）、截止日期
- 【落盘】新建 `看板数据固化/源文件/RPA落盘/P93_众筹快照_YYYYMMDD.csv`（YYYYMMDD=当天日期）
- 列：`数据日期,排名,项目名,众筹金额USD,支持人数,完成度%,链接`
- 数据日期=今天（YYYY-MM-DD）；链接列为项目页 URL
- 【校验】行数=12；金额列均为纯数字；完成后向操作者口头汇报"首条项目名+金额"供抽验

## 任务二：P46/P48 IDC 季度核对（检索 API 搜不到新稿时的人工核对）

**背景**：IDC 官网检索 API（press-release search）排前结果常为旧季度综述稿，最新季度稿未入检索
（2026-10-31 实测：P46 检索最新仅 2025Q1 稿，而数据已到 2026Q2）。季度发布窗口（每季末后 4~8 周）
用本任务人工核对一次。

【锚点校验】仅需浏览器访问核对，若网站改版导致锚点不存在，直接汇报"锚点失效"勿猜测。

- 打开 `https://www.idc.com/getdoc.jsp?containerId=prUS49446024` 无效时改走首页路径：
  `https://www.idc.com` → 顶部菜单 Press Room / Newsroom → Press Releases
- 在检索框分别搜索：`wrist-worn`（P46 腕上设备）、`tablet`（P48 平板）、`smartphone`（P44 参考）
- 对每条标题含 `Global` 且为最近一个季度的稿子：记录稿标题、发布日期、稿内数据季度
- 与看板数据比对：
  - P46 → `看板数据固化/CSV数据/行业数据-P46-穿戴设备.csv`
  - P48 → `看板数据固化/CSV数据/行业数据-P48-平板出货量.csv`
- 【落盘】新建 `看板数据固化/源文件/RPA落盘/P46P48_IDC季度核对_YYYYMMDD.csv`
- 列：`核对日期,词条,稿标题,稿发布日期,稿数据季度,看板最新季度,结论(一致/看板落后/稿为旧季度)`
- 【校验】每条结论三选一必填；若"看板落后"，把稿内出货量与同比数值附在最后一列
