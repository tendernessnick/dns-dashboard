# 固化数据存储规范

> 数据治理 · 阶段1产出 ｜ 生效日期 2026-10-28 ｜ 适用 `看板数据固化/` 全部持久化产物
> 阶段2按本规范批量迁移现有 74 个 CSV；迁移前逐文件 diff 验证，历史行零丢失。

## 1. 目录规则

```
看板数据固化/
├── CSV数据/            仅存放"在用"词条CSV（时序型/快照型/面板型），文件名=板块-P序号-条目.csv
│   └── _归档/          旧口径存档、被替换的历史schema文件（生成数据.py 显式排除本目录）
├── 验证/               交叉验证等运行性产物（非词条数据；cross_check.py 输出改落此处）
├── 资讯数据/           资讯JSON（近7天口径）
├── 采集日志.csv        运行日志（结构见 §6）
└── 词条注册表.csv      唯一元数据事实源（见《词条注册表设计》）
```

规则：
- `CSV数据/` 下**禁止**出现非 `-P数字-` 命名的文件；运行性产物一律不进此目录。
- 归档文件移入 `_归档/` 时文件名保持原样；`生成数据.py`/`load_data` 以目录白名单方式只读 `CSV数据/*.csv`（递归关闭）。
- 首个迁移对象：`产品品类-P72-价格带结构-旧口径存档.csv` → `_归档/`；`交叉验证-行情双源对照.csv` → `验证/`。

## 2. 两套 Schema 标准

### 2.1 时序型（默认，适用大多数词条）

| 列 | 必/选 | 规范 |
|---|---|---|
| 数据日期 | 必 | 第一列，YYYY-MM-DD（期间期末）；主键 |
| 数值列… | 必 | 纯数字（无千分位/符号）；**新增列不再允许单位嵌入列名**；存量列名的括注单位迁移时保留（人读），机读以"单位"列为准 |
| 单位 | 必（阶段2补齐） | 该行数值的单位；多品类同单位共一个值；一个文件仅一种单位，混单位拆文件 |
| 数据来源 | 必 | 标准措辞（见 §3），≤20字 |
| 备注 | 必 | 口径说明 / 推算说明 / 佐证URL，多段用"；"分隔；见 §4 |

- 主键 = `数据日期`；重复采集按日期 upsert（同日覆盖、跨日追加）。
- 面板型（P201-P234）按主键含报告期，属时序型特例；安克公告/募投（P78/P81）迁移时新增 `链接` 列（PDF URL 从备注迁出，生成数据.py 改读链接列、兼容读备注）。

### 2.2 快照型（榜单/多行同日：P66/P68/P70/P76/P77/P83/P92/P93/P94/P95/P98/P99）

| 列 | 必/选 | 规范 |
|---|---|---|
| 数据日期 | 必 | 快照日 |
| 排名/业务键 | 必 | 联合主键组成部分（榜单=排名；互动=公司+类型等） |
| 属性列（标题/价格/图片URL…） | 可选 | 附件类列（图片URL等）置于业务键之后、数据来源之前 |
| 数据来源 | 必 | 同 §3 |

- 主键 = `数据日期 + 业务键`；**无备注列要求**、无单位列（价格类单位入列名）。
- 历史快照全量保留，暂不清理（P2-5 保留策略待条目量增长后再议）。

### 2.3 禁止事项

- 禁止无"数据来源"列的词条CSV；禁止一表混多种主键；禁止日期格式混写（如 `2026/10/1`）。
- 修改表头必须走迁移流程（§5）：`save_row` 阶段2起对表头不符**拒绝写入并告警**，不再静默清空重建。

## 3. 数据来源措辞标准

格式：`机构(通道/数据集)`，全称≤20字；同一来源全库措辞唯一。标准措辞表（迁移目标）：

| 标准措辞 | 覆盖 |
|---|---|
| `东方财富(行情API)` | push2/em_kline 系 |
| `东方财富(数据中心·PPI)` 等 | RPT_ECONOMIC 系（数据集名缩写入括号） |
| `新浪财经(行情API)` / `新浪财经(期货行情)` | hq.sinajs / 期货K线 |
| `Eurostat(PRC_HICP_MANR)` 等 | 官方API按数据集名 |
| `生意社(100ppi)` | 现货基准/参考价 |
| `IDC(新闻稿转引)` | P43-P49（含"考证推算"进备注） |
| `TradingEconomics(镜像页)` | P09/P11 |
| `Amazon(Best Sellers)` | P66/P68 |
| `巨潮资讯(公告接口)` / `互动易(接口)` | P78/P81/P231-234 / 互动类 |
| `WPC(认证产品库)` / `TrendForce(现货页)` / `立创商城(现货页)` / `上海航运交易所` / `IATA(RSS)` / `国家统计局(东财通道)` / `FRED(RSEAS)` / `欧盟委员会(DG ECFIN)` 等 | 对应词条 |

**溯源豁免条款（阶段0审计后补充）**：含转引出处、考证日期、逐条出处的行级措辞——
如 `IDC（转引：FoneArena 2024-08）`、`国家统计局月度稿（原文, 2024-07-15）`、`上海航交所（转引：…）`——
**其本身即溯源信息，原样保留不缩写**（缩写即丢溯源，违背治理红线2）。
措辞标准化仅适用于高频通道型取值（如裸"东方财富"、`生意社 100ppi.com`），
以"值→标准值"映射表执行，未命中映射的值一律不动。

迁移规则：旧措辞 → 标准措辞做**映射表**逐文件替换；映射表随迁移diff报告存档。

## 4. 备注列语义

备注列允许三类内容，组合时以"；"分隔：
1. **口径说明**：如"期货主力连续（历史回填）""代理口径""快报值，正式值发布后自动替换"；
2. **推算/考证说明**：如"推算=前三季累计139.0−Q1−Q2"；
3. **佐证URL**：新闻稿/文章链接。

禁止：把备注当唯一业务字段（URL 为程序消费的须走专用列，如公告类 `链接` 列）；禁止空泛填充（"每日更新"这类信息属于注册表，不进备注）。

## 5. Schema 变更迁移流程

1. 变更提案（改哪个文件、加/改哪列、影响行数）→ 记入治理文档；
2. 编写一次性迁移脚本：读旧行 → 按新表头重写 → **前后 diff 验证**（行数相等、非涉及列数值逐行一致）；
3. 同步修改对应采集器的 COLUMNS 常量；
4. 阶段2起 `save_row` 表头校验：与现存表头不一致直接 raise（提示走迁移），杜绝清空重建。

## 6. 采集日志标准

列（阶段2升级，兼容追加）：`run_id, 采集时间, P号, 词条, 状态(成功/失败/跳过), 耗时秒, 回填策略, 详情`。
- run_id = `YYYYMMDD_HHMMSS`（一次 run_all 批次共用）；
- 旧格式行保留不迁移；新行一律新格式；
- 日志文件被占用（Excel打开）时跳过写入不影响采集（现状保留）。

## 7. 资讯JSON标准结构

```json
{"updated": "ISO时间", "source": "来源名",
 "items": [{"date": "MM-DD", "title": "原题", "title_zh": "中文翻译(可空)", "url": "https://…"}]}
```
- `title_zh`：英文源必须尝试翻译（失败留空）；中文源留空；
- 扩展字段允许（如众筹的金额/达成率），但须在注册表"备注"登记字段名；
- 保留近 7 天口径不变；`items` 按时间降序、≤8 条。
