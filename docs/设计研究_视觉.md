# 数据看板视觉设计研究 —— 面向全员的企业级"严肃精美"规范

> 适用对象：现有单 HTML 数据看板（Bento 布局，5 大板块 94 词条，品牌蓝 #0065B0，微软雅黑，浅色主题，红涨绿跌）的整体重设计。
> 研究参照系：Bloomberg Terminal（信息密度与秩序）、WSJ / The Economist（报头气质与图表克制）、麦肯锡图表页（深蓝主色 + 银灰）、Stripe / Mercury（金融数字排版与"冷静即可信"）、Datawrapper / FT Visual Vocabulary（组织级图表配色方法论）、Atlassian Elevation（阴影 token 化）。
> 核心结论先行：**严肃感来自"克制的色 + 严苛的网格 + 精确的数字排版 + hairline 层级"，而不是装饰。** 机构级产品普遍是"中性灰阶打底、品牌蓝唯一强调、红绿只许表达涨跌"。

## 一、设计 Tokens（可直接复制为 CSS 变量）

### 1.1 中性色阶（9 档，冷调微蓝灰，与品牌蓝 #0065B0 同族）

| Token | HEX | 角色 |
|---|---|---|
| `--n-0` | `#FFFFFF` | 卡片面 surface |
| `--n-25` | `#F7F9FA` | 悬停底、斑马纹、表头底 |
| `--n-50` | `#F1F4F6` | 画布底（页面背景） |
| `--n-100` | `#E6EBEF` | 网格线、行分隔线、skeleton |
| `--n-200` | `#D7DEE4` | 卡片 hairline 边框 |
| `--n-300` | `#BFC9D1` | 加重边框（hover / 分组线）、轴 |
| `--n-500` | `#61707C` | 次要文字、标签、轴刻度（白底对比 5.1:1） |
| `--n-700` | `#333F49` | 正文、表格内容 |
| `--n-900` | `#0F1820` | 标题、主数值（"墨色"，不是纯黑） |

> 12px 以下小字只用 N500 及以上；N500 在 N25/N50 底上用于 12px 时需升到 N700（对比度不足时灰阶让位）。

```css
:root {
  --n-0:#FFFFFF; --n-25:#F7F9FA; --n-50:#F1F4F6; --n-100:#E6EBEF;
  --n-200:#D7DEE4; --n-300:#BFC9D1; --n-500:#61707C; --n-700:#333F49; --n-900:#0F1820;
}
```

### 1.2 品牌蓝阶

| Token | HEX | 用途 |
|---|---|---|
| `--brand-ink` | `#063D66` | 深蓝标题/顶栏深色 |
| `--brand-700` | `#005A9E` | hover 态主色 |
| `--brand` | `#0065B0` | 主线、主分类、链接、焦点（白底文字对比 6.0:1） |
| `--brand-300` | `#7FB3D8` | 图表第二系列、对比期虚线 |
| `--brand-100` | `#E5F0F8` | 选中底、面积图浅端 |

**规则：品牌蓝只允许出现在 4 类地方——①图表主线/主分类 ②链接与当前态 ③焦点环 ④顶栏。** 不做彩色按钮、不做蓝色大色块卡片（深蓝仅限顶栏/报头）。

### 1.3 语义色（去饱和、稳重值，全部通过白底 4.5:1 文字对比）

| Token | 文字/主线 | 浅底 fill | 边框 | 说明 |
|---|---|---|---|---|
| 涨 `--up` | `#B42318`（6.6:1） | `#FBEFED` | `#EFC4BD` | 仅用于上涨、超目标、同比为正 |
| 跌 `--down` | `#0E7A54`（5.3:1） | `#EAF5F0` | `#BFE0D2` | 仅用于下跌、未达标 |
| 警示 `--warn` | `#B54708`（5.4:1） | `#FFF6E8` | `#F3D9A4` | 数据缺失、口径变更、临近阈值 |
| 危险 `--danger` | `#9F1D14` | `#FBEFED` | `#E9B3AC` | 与"涨红"同族但更深，必须配图标 |
| 成功/正常 `--ok` | `#0B5FA5` | `#E9F2F9` | `#BBD6EA` | **刻意用蓝而不用绿**，避免与"跌绿"冲突 |
| 中性/其他 `--na` | `#61707C` | `#F1F4F6` | `#D7DEE4` | 无数据、不适用 |

> 无障碍铁律：红绿色盲（约男性 8%）下 #B42318 与 #0E7A54 明度接近，**涨跌绝不允许只靠颜色区分**，必须成对给 ▲/▼ 符号或 +/− 号（见技法 4）。

### 1.4 字号阶梯（px / 行高 / 字重）

| 层级 | px/行高 | 字重 | 用途 |
|---|---|---|---|
| Hero 数值 | 34/40 | 700 | 每屏至多 1 个（板块头条数） |
| KPI 大数 | 28/36 | 700 | KPI 卡主数值（下限 24px） |
| 次级数值 | 22/30 | 600 | 次重要指标、表格合计 |
| 卡片标题 | 16/24 | 600 | 卡片标题、面板标题 |
| 正文/表格 | 14/22 | 400–500 | 表格内容、资讯正文 |
| 辅助文字 | 13/20 | 400 | 说明、口径注释 |
| 标签/轴 | 12/18 | 500–600 | eyebrow、表头、轴刻度（可读性下限） |
| 时间戳 | 11/16 | 400 | 仅次要元数据（更新时间、来源） |

> 层级优先靠**字重（400/500/600/700 四档）+ 灰阶**拉开，而非无限放大字号——数据密集 UI 中字号空间很快用完（Stripe/彭博做法）。禁用 400 与 700 之外的中间字重，避免渲染发虚。

### 1.5 间距基准（4px 基数，8pt 节奏）

`4 / 8 / 12 / 16 / 20 / 24 / 32 / 40 / 48 / 64`

- 页面：最大宽度 1440px（宽屏可放到 1600px），左右留白 32px；画布底 N50。
- 网格：12 列，列距（gap）**12px**，板块之间垂直间距 **40px**（紧凑模式 32px）。
- 卡片：内边距 **20px**（≥600px 宽的卡片用 24px；小 KPI 卡 16px）。
- 卡内节奏：eyebrow→标题 6px，标题→内容 12px，数值→元信息 8px。

### 1.6 圆角阶梯（小圆角 = 严肃；含 Bento 间距配比公式）

| Token | 值 | 用途 |
|---|---|---|
| `--r-xs` | 4px | 状态 chip、表格内标签、迷你条形 |
| `--r-sm` | 6px | 按钮、输入框 |
| `--r-md` | 8px | 卡内嵌块（缩略图、mini chart、代码块） |
| `--r-lg` | 12px | **卡片标准圆角** |
| `--r-xl` | 16px | 仅 hero 大面板，全页最多 1–2 个 |

Bento 配比公式（来自 setproduct 网格拆解）：**gap = 圆角的一半到一倍**（12px 圆角配 8–12px gap）；嵌套圆角 = 外圆角 − 内边距，下限 4px。按本规范：卡片 r12 + gap12 + padding20，卡内嵌块 r8，成立。**禁用 ≥20px 圆角**（气泡感、玩具感）。

### 1.7 阴影层级（hairline 为主、阴影为辅；ink 色 rgba(15,24,32,…)）

```css
:root {
  /* L0 静置卡片：1px hairline + 近零阴影（机构级"平面但有层"的标准做法） */
  --shadow-0: 0 1px 2px rgba(15,24,32,.04);
  /* L1 hover：抬升 1px */
  --shadow-1: 0 2px 4px rgba(15,24,32,.05), 0 8px 16px -4px rgba(15,24,32,.08);
  /* L2 浮层：下拉、tooltip、popover */
  --shadow-2: 0 4px 8px -2px rgba(15,24,32,.08), 0 16px 32px -8px rgba(15,24,32,.12);
  /* L3 模态 */
  --shadow-3: 0 8px 12px -4px rgba(15,24,32,.10), 0 28px 56px -12px rgba(15,24,32,.18);
  /* 焦点环 */
  --ring-focus: 0 0 0 3px rgba(0,101,176,.16);
}
.card { border:1px solid var(--n-200); border-radius:12px; background:var(--n-0);
        box-shadow: var(--shadow-0); }
.card:hover { border-color: var(--n-300); box-shadow: var(--shadow-1);
              transform: translateY(-1px); transition: all .12s ease-out; }
```

> 规则：**每张卡片同时只有一层阴影**；阴影只随交互加深，不随卡片重要性变化（重要性靠面积与位置表达）。顶栏/浮层才允许 L2。

## 二、12 条具体技法（做什么 + 为什么 + 怎么落地）

### 技法 1：Eyebrow 微标签——每张卡片的第一行
- **做什么**：卡片内容之前放一行 11–12px、字重 600、全大写（中文则加字距不转大写）、颜色 N500 的分类微标签，如 `01 宏观环境`；可选在左侧加 3×12px 品牌蓝竖条。
- **为什么**：94 张卡片必须靠"统一的第一行"建立扫描秩序。REI、Apple、经济学人均以 eyebrow 承担分类导览；它让眼睛在 0.5 秒内完成"这是什么板块"的判断。
- **CSS**：
```css
.eyebrow { display:flex; align-items:center; gap:6px;
  font-size:12px; font-weight:600; color:var(--n-500);
  letter-spacing:.08em; text-transform:uppercase; }
.eyebrow::before { content:""; width:3px; height:12px;
  background:var(--brand); border-radius:1px; }
/* eyebrow 与标题间距 6px，标题 16px/600 N900 */
```

### 技法 2：Hairline 分隔体系——线代替阴影
- **做什么**：卡片边框 1px N200；卡片内部分区（表头与表体、标题与内容、时间线项与项）一律 1px N100 实线；分组级分隔才用 N300。
- **为什么**：机构级界面（Stripe、Mercury、FT）用"hairline + 近零阴影"表达层级，避免重阴影带来的悬浮感/玩具感；线是"文档感"，阴影是"应用感"，严肃受众更信任前者。
- **CSS**：`border-bottom:1px solid var(--n-100);` 全局统一，禁止 2px 以上分隔线与虚线混用（虚线只允许出现在图表基准线）。

### 技法 3：数字排版铁律——tabular-nums + 定宽 + 单位缩小
- **做什么**：所有数值元素 `font-variant-numeric: tabular-nums`；表格数字列右对齐并给固定 `ch` 宽度；千分位统一；小数位全站统一（指数 2 位、百分比 1 位）；货币/单位（元、%、亿）用 0.6em、字重 400、N500。
- **为什么**：等宽数字让多行数值纵向成列，是金融 UI 可信度的第一来源（Stripe 的标志性细节）；单位缩小让"数"成为主角，彭博与 WSJ 均如此。
- **CSS**：
```css
.num, td.num, .kpi-value, .axis-tick {
  font-variant-numeric: tabular-nums;
  font-feature-settings:"tnum" 1;
  font-family:"Segoe UI","Helvetica Neue",Arial,"Microsoft YaHei",sans-serif; }
td.num { text-align:right; min-width:9ch; }
.unit { font-size:.6em; font-weight:400; color:var(--n-500); margin-left:2px; }
```
> 注意：微软雅黑部分字重的 tnum 支持不稳定，数值元素请按上面字体栈优先用 Segoe UI/Arial 渲染数字，中文标签仍用雅黑。

### 技法 4：涨跌色只表达方向，且必配符号
- **做什么**：涨 `#B42318`、跌 `#0E7A54` 只出现在：涨跌值、▲▼ 符号、迷你趋势、状态 chip。涨跌值写成 `▲ +4.1%` / `▼ −2.3%` 的整段形式，符号 10px、数值 12–14px tabular。
- **为什么**：①"颜色只表达状态"是 Stripe/Mercury 的核心纪律，一旦彩色参与装饰，数据语义立即稀释；②红绿色盲需要形状冗余。
- **CSS**：
```css
.delta { font:500 12px/1 var(--font-num); font-variant-numeric:tabular-nums; }
.delta.up   { color:var(--up); }   /* 内容：<span>▲</span>+4.1% */
.delta.down { color:var(--down); }
.delta .arrow { font-size:10px; margin-right:2px; }
```

### 技法 5：图表规范——线宽、刻度、网格线的硬指标
- **做什么/参数**：主线 **2px** 品牌蓝实线；对比期 **1.5px** brand-300 或 `4-3` 虚线；历史基准 **1px** N300 虚线；横向网格线 **1px N100 实线，只留横线不留竖线**；轴刻度文字 **12px N500**，y 轴 4–6 档、小数位固定；面积填充用 8–12% 透明度到 0 的垂直渐变；末点画 4px 白心蓝环点 + 数值标签；图例用 8px 圆点 + 12px 文字，不画边框盒。
- **为什么**：经济学人/FT 图表 ~90% 是细线 + 淡网格的条形/折线，"颜色做减法、网格做减法"正是权威感的来源；竖网格线与重图例盒是仪表盘"廉价感"的前两名。
- **CSS（以 SVG/ECharts 为例的对应项）**：
```js
// ECharts 对应
lineStyle:{width:2,color:'#0065B0'},
symbol:'circle', symbolSize:0, // hover 时 7
splitLine:{lineStyle:{color:'#E6EBEF',width:1}},
axisLabel:{color:'#61707C',fontSize:12,fontFamily:'Segoe UI'},
areaStyle:{color:'rgba(0,101,176,.10)'},  // 渐变至 0
```

### 技法 6：留白节奏——4/8pt 网格，密度靠行高不靠缝
- **做什么**：全局 4px 基数；卡片 gap 12px、板块间 40px；卡内 padding 20px；资讯/表格行高 **44px**（信息密度高时 40px），行与行不加额外 margin。
- **为什么**：Bento 网格的秩序感来自"间距=圆角一半到一倍"的数学关系；行内密度高、行间留白足，是 Bloomberg"高密度不混乱"的关键——压缩的永远是行高而不是缝隙。

### 技法 7：表格规范——财务级的行列纪律
- **做什么**：表头 12px/600 N500、底 N25、sticky；行高 40–44px、行分隔 1px N100、不斑马纹（斑马纹仅在 >10 行时启用 N25）；文本列左对齐、数值列右对齐 `9ch` 定宽；首列允许 sticky；悬停整行 N25；合计行上边框 1px N300 + 字重 600。
- **为什么**：表格是研报看板中最"机构"的组件，Stripe 的表格规范（右对齐、tabular、行内 sparkline、状态 chip）直接可用。
- **CSS**：
```css
table { border-collapse:separate; border-spacing:0; width:100%; }
th { font:600 12px/18px var(--font); color:var(--n-500); background:var(--n-25);
     padding:10px 12px; border-bottom:1px solid var(--n-200); position:sticky; top:0; }
td { font:400 14px/20px var(--font); color:var(--n-700);
     padding:10px 12px; border-bottom:1px solid var(--n-100); }
tbody tr:hover { background:var(--n-25); }
```

### 技法 8：Hover 层级——只允许"1px 抬升 + 边框加深"
- **做什么**：卡片 hover：`translateY(-1px)` + 边框 N200→N300 + shadow-0→shadow-1，**120ms ease-out**；可点击行/资讯条目 hover 仅底色 N25；绝不使用 scale 放大、变色光晕。
- **为什么**：链接卡片与词条卡片需要可点击暗示，但放大动画在 94 卡的密集页面里会制造抖动与眩晕；1px 抬升是 Atlassian/Linear 一系的克制做法。
- **CSS**：
```css
.card { transition: box-shadow .12s ease-out, transform .12s ease-out,
        border-color .12s ease-out; }
.card:hover { transform:translateY(-1px); }
@media (prefers-reduced-motion: reduce){ .card{ transition:none; transform:none; } }
```

### 技法 9：资讯列表与时间线——左轨 + 定宽时间列
- **做什么**：时间线用 **2px N200 左轨** + 8px 事件点（重要事件品牌蓝、普通事件 N300 白心）；时间戳放 **定宽 64px 的 12px tabular N500 列**，标题 14px N800 单行截断（`text-overflow:ellipsis`），来源 12px N500 右对齐。资讯行高 44px。
- **为什么**：定宽时间列让纵向扫读形成一条直线（同技法 3 的 tabular 逻辑）；左轨把"时间方向"物理化，比纯列表更有档案感。
- **CSS**：
```css
.timeline { border-left:2px solid var(--n-200); padding-left:16px; }
.timeline li { position:relative; padding:8px 0; }
.timeline li::before { content:""; position:absolute; left:-21px; top:14px;
  width:8px; height:8px; border-radius:50%;
  background:var(--n-0); border:2px solid var(--n-300); }
.timeline li.hot::before { border-color:var(--brand); }
```

### 技法 10：状态 Chip——充色不超过 12% 饱和底
- **做什么**：chip 高 22px、padding 2px 8px、圆角 4px、12px/600；配色永远用 1.3 的"文字+浅底+边框"三元组（如警示：#B54708 / #FFF6E8 / #F3D9A4）；不用纯色底白字。
- **为什么**：纯色底 chip 在密集页面里会变成一串"彩色纽扣"，抢走数据的注意力；浅底 chip 保持 90% 以上的页面中性。
- **CSS**：
```css
.chip { display:inline-flex; align-items:center; height:22px; padding:0 8px;
  border-radius:4px; font:600 12px/1 var(--font); }
.chip.warn { color:var(--warn); background:#FFF6E8; border:1px solid #F3D9A4; }
```

### 技法 11：可信度元信息行——数据截至、来源、口径显性化
- **做什么**：每张数据卡片底部放 11–12px N500 元信息行：`数据截至 2026-10-23 08:30 · 来源：Wind`；页面级在报头/顶栏放全局"数据截至"时间；口径变化的卡片在角落放警示 chip。
- **为什么**：WSJ/经济学人的权威一半来自"出处感"；全员使用的看板最大的不信任来源是"这数是谁、什么时候算的"。这是零成本、高回报的严肃感装置。
- **CSS**：`.meta { font:400 11px/16px var(--font-num); color:var(--n-500);
  border-top:1px solid var(--n-100); padding-top:8px; margin-top:auto; }`（卡片用 flex column，meta 沉底对齐）。

### 技法 12：空态与加载——骨架屏代替转圈
- **做什么**：加载中用 N100 色块骨架（圆角同内容、高度同内容，微呼吸动画 opacity .5↔1, 1.2s）；空态一句话 + 数据来源提示，不放插画。
- **为什么**：Bloomberg 式工具的关键体验是"永远有内容在原位"；spinner 会引起布局跳动，插画空态会破坏严肃气质。
- **CSS**：
```css
.skeleton { background:var(--n-100); border-radius:8px;
  animation:pulse 1.2s ease-in-out infinite; }
@keyframes pulse { 50% { opacity:.55; } }
```

## 三、Masthead / 顶栏方案（3 选 1，均含"数据截至"位）

### 方案 A：报头式（Editorial Masthead，最"出版物"，推荐对外/汇报）
结构（自上而下）：
1. **3px 品牌蓝通栏 rule**（页面最顶端，全程 sticky 时保留）；
2. 白底报头区（padding 24px 32px）：左侧公司名 12px N500 全大写字距 .08em → 主标题"研报数据看板"26px/700 N900（中文加字距 .02em）→ 副标题 13px N500（期数/范围）；右侧右对齐两行：`数据截至 2026-10-23 08:30`（12px tabular N700）+ `更新频率：每周五 17:00`（11px N500）；
3. **双细线**：上 1px N300 + 下 3px N900（或品牌蓝），经济学人式报头签名；
4. 40px 白底 sticky 工具条：5 大板块锚点（12px/600，当前项文字品牌蓝 + 底部 2px 品牌蓝指示条，其余 N500），右端"打印/全屏"图标钮。
- 气质参数：无深色块、无阴影，全靠 rule line；与正文同为白底，纸感最强。

### 方案 B：终端式命令条（Command Bar，最"工具"，推荐日常高频使用）
结构：
1. **48px 深色条**：底色 `#10171E`（N900）或 `#063D66`（brand-ink）；左：16px logo + 系统名 13px/600 白字；中：5 板块 tab（高 48px，白字 12px，激活项底部 2px `#0065B0`，非激活 60% 白）；右：`数据截至 08:30`（12px tabular）+ 时钟 + 全屏钮；条与内容间 1px `rgba(255,255,255,.12)` 内线。
2. 其下 **32px 白底 ticker 条**（hairline 下边框）：8–10 个核心指数横向滚动，`名称 3,088.45 ▲+0.62%`，12px tabular，红涨绿跌；hover 暂停。
- 气质参数：向 Bloomberg 致意但保持浅色正文；深色只占 48px，页面 95% 仍是浅色，严肃而不压抑。

### 方案 C：蓝幅式（Brand Band，最"企业正式"，推荐领导首页）
结构：
1. **88px 深蓝横幅**：纯色 `#063D66`（忌大面积渐变；如需层次，叠加 4% 白色自左向右提亮）；左：主标题 22px/700 白 + 副标题 12px 白 70%；右：报告周期 `2026 W43`（14px tabular 白）；
2. 横幅底缘 **2px `#0065B0`** 品牌线；
3. 之下是 N50 画布 + 12px gap 的 Bento 区；锚点导航并入横幅底行或省略（单屏滚动场景）。
- 气质参数：唯一的"深色大面积"方案，仪式感最强，适合季度/月度汇报态；日常浏览建议 A/B。

## 四、Do / Don't 清单（面向严肃企业受众）

### DO（做）
1. 每张卡片固定三件套：eyebrow → 标题（16px/600）→ 元信息沉底；94 张卡共用同一模板。
2. 所有数值 tabular-nums、右对齐、小数位全站统一；表格数值列给 `ch` 定宽。
3. 涨跌必带 ▲▼ 或 +/− 符号与文字，颜色只是第二编码。
4. 品牌蓝只用于：图表主线、当前态、链接、焦点环、顶栏；其余一切保持灰阶。
5. 卡片一律 1px N200 hairline + shadow-0，hover 才升 L1；全页同时最多一个 L2 浮层。
6. 遵守 4/8pt 网格：gap 12、卡 padding 20、板块间 40、行高 44。
7. 图表做减法：只留横向 1px N100 网格线，轴字 12px N500，主线 2px，末点标数值。
8. 显性化"数据截至 + 来源 + 口径"，元信息行每卡必有。
9. 图表与表格联动表达：图表是表格的摘要（Stripe 原则），卡内 mini chart 与主表同一配色。
10. 深蓝/深灰只出现在顶栏与 hero（≤10% 版面），保持浅色为绝对主导。
11. 无障碍：正文对比 ≥4.5:1，`focus-visible` 用 3px 品牌蓝 16% 环，尊重 `prefers-reduced-motion`。
12. 打印/投屏自查：灰阶打印后层级仍成立（N100/N200/N300 拉开明度）。

### DON'T（不做）
1. 不用彩虹分类色：单图分类 ≤4 个，超过改用同色系明度阶或合并为"其他"（灰）。
2. 不用纯红 #FF0000 / 纯绿 #008000 / 荧光色；语义色一律用 1.3 的去饱和值。
3. 不用大圆角（≥20px）、糖果色渐变、玻璃拟态、霓虹发光阴影。
4. 不给数据区加装饰渐变与彩色卡头；彩色渐变只允许出现在图表面积填充（≤12% 透明度）。
5. 不用纯黑 #000 正文与大面积 80px+ 巨字号；数值上限 34px，每屏至多 1 个。
6. 不居中排版正文、不斜体中文、不用衬线中文正文（衬线仅可选用于报头两字标题）。
7. 不用 spinner 与弹跳加载动画；不用 hover scale 放大。
8. 不让数字换行/截断——截标题可以，截数值等于改数据。
9. 不在小卡片堆三种以上信息形态（图+表+长文同卡）；一卡一个主形态。
10. 不用竖网格线、3D 饼图、双 y 轴、截断 y 轴的柱状图。
11. 不隐藏或省略"数据截至"时间；不用"最新""刚刚"等模糊时间词。
12. 不混用两套字体栈与两套阴影风格；同一层级内 padding/gap 必须一致。

## 五、三个候选风格方向

### 方向一：「机构纸白」Institutional Paper —— 经济学人/麦肯锡图表页
像一份数字化的研究简报：纯白卡面落在 N25–N50 极浅画布上，几乎无阴影（hairline 即层级），报头式 masthead（方案 A）配双细线，图表是最克制的单蓝细线 + 淡网格。**关键参数**：画布 `#F7F9FA`、卡片 r8–12、gap 12、shadow-0、强调色仅品牌蓝、字体 95% 雅黑 + 数字 Segoe UI、图表单系列为主。适合追求"出版物权威感"、以阅读为主的场景；风险是初看偏素，需要靠报头与 tick 细节撑住精致度。

### 方向二：「精密终端」Precision Desk —— Bloomberg 密度 × Stripe 克制（推荐日常态）
信息密度最高的方向：深色 48px 命令条 + 白色 ticker 滚动条（方案 B），画布 N50 上以 12px 紧 gap 铺设 94 张白卡，数字全部 13–14px tabular 右对齐，表格与 sparkline 承担主要表达，色彩几乎只剩红绿涨跌与品牌蓝。**关键参数**：画布 `#F1F4F6`、r12、gap 12、行高 40–44、KPI 24–28px、图表 2px 线 + 末点标签、允许每卡一条 1px 内 hairline 分区。适合全员每天打开 5 分钟的"工作台"定位；风险是密度高，必须严守网格否则显挤。

### 方向三：「深蓝权威」Executive Navy —— 报告封面的仪式感
把"汇报场合"前置：88px 深蓝横幅（`#063D66`）+ 2px 品牌蓝底缘（方案 C），横幅下第一屏放一个深蓝 hero 面板承载 3–4 个 headline KPI（白字 tabular + brand-300 点缀），其余板块回落到浅色精密卡片区。**关键参数**：深色占比 8–12%、hero KPI 28–34px 白字、正文区与方向二参数一致、语义色不变（红绿在深蓝底上改用 #E88C7D/#5FC49A 亮阶仅限 hero 内）。适合月度/季度汇报与对外展示双模式切换；风险是两套前景色阶（深/浅）需各自校对比度，维护成本最高。
