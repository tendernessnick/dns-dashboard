## 二、CSV规范

- 编码 **utf-8-sig**（Excel双击直接打开不乱码）；第一列 `数据日期`（YYYY-MM-DD = 数据所属期间期末）
- 数值列**纯数字**（无千分位），可直接绘图；**多品类/多型号条目一列一个品类**（如芯片4型号、存储5品类、品牌份额多品牌）
- **按日期行迭代**：重复采集自动按日期upsert（同日覆盖、跨日追加），不会产生重复行
- 每行带 `数据来源` 列；多行快照型（Amazon榜单）用 日期+排名 联合主键

## 五、使用方法

```bash
# 日常更新（v12数据/页面分离：只重写 data.js，页面壳不动）
cd 看板数据固化/采集脚本
python run_all.py            # 全量采集（数值写CSV数据/，资讯写资讯数据/）
python run_all.py P26 P36    # 只跑指定词条
python collect_P26_LME铜.py  # 单独跑一个
python cross_check.py        # 行情交叉验证

cd ../../看板
python 生成数据.py           # CSV+资讯JSON → data.js（毫秒级；或直接双击 更新看板.bat 一键完成前两步）
python 打包单文件.py          # 需要发同事时：壳+数据内联成 数据看板-单文件版.html
```

**v13模块化（2026-10-29）**：页面壳由 `看板/生成看板.py` 组装——`看板骨架.html` + `布局.csv` + `模块/*.json`（一卡一配置）+ `渲染器/*.js`。改卡片文案/绑定、挪卡加卡、改卡型渲染，分别只动对应 JSON / 布局.csv / 渲染器文件，然后 `python 生成看板.py` 重建壳（秒级、确定性，其他卡零影响）；规范与改动配方见 `docs/看板模块化/00_模块化设计与规范.md`。data.js 仍只由 生成数据.py 重写（勿手改）。旧 `看板模板.html` 已废弃（仅作拆卡迁移源保留，v12完整备份在 `看板/_备份_v12模块化前/`）。

建议频率：行情/资讯类**每日**（资讯自动只保留近7天）；宏观类**每月发布后**；季度类**每季**。
RPA类（P07/P12/P28/P29/P53/P70/P73/P76/P77/P83/P98/P99）按 `RPA任务提示词.md` 逐条建ZCode定时任务，提示词可直接粘贴。

## 七、注意

1. **口径标注**：P31/32/39/40 的曲线是期货主力（历史回填），大数值是生意社现货——两者并列已在其CSV分列，卡面有"期货主力连续（历史回填）"标注；引用时注意区分。
2. P06 PPI环比为统计局新闻稿标题口径，自2026-08起逐月积累，前期留空属正常。
3. 源站结构变更会导致采集失败——失败记录在 `采集日志.csv`，不会写入编造数据；修复脚本即可续上。
4. 引用数据请注明原始来源（每个CSV的"数据来源"列 + 页底溯源索引 + 考证文件）。
5. **显示窗口（v10引入，v12治理起由注册表驱动）**：折线图默认只渲染最近一段窗口（每词条的
   「显示窗口」配置在 `词条注册表.csv`，由 生成数据.py 派生），
   顶栏「周期」选择器可临时切换 3月/6月/1年/3年/全部。仅影响看板渲染，CSV 固化数据始终保留全量历史。
