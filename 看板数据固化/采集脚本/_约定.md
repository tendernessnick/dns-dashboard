# 数据固化采集约定（批次代理必读）

## 目录
- CSV输出：`看板数据固化/CSV数据/`
- 采集脚本：`看板数据固化/采集脚本/collect_P{序号2位}_{短名}.py`
- 共享库：`采集脚本/common.py`（http_get/http_post/save_row/log_result/hw_check_get/em_get/em_kline/sina_hq/sina_kline/parse_date_label）
- 运行器：`采集脚本/run_all.py`（自动发现collect_P*.py）

## CSV命名
`{板块}-P{序号}-{条目短名}.csv`，例：`大宗商品-P26-LME铜价.csv`、`宏观数据-P04-10年期美债收益率.csv`

## CSV表头（schema）
- 单指标：`数据日期,数值,单位,数据来源,备注`
- 多指标：`数据日期,指标1,指标2,...,数据来源,备注`
- 数值列纯数字（无千分位）；第一列必须为"数据日期"（YYYY-MM-DD = 数据所属期间期末，无期间信息则用抓取日；common.parse_date_label可转换）
- 编码 utf-8-sig；save_row按日期upsert，重复采集不会产生重复行

## 采集器规范
- 文件头注释：`"""P{序号} {板块}-{词条}：来源+方法一句话"""`
- 必须暴露 `run() -> (status, detail)`，status ∈ 成功/失败/跳过
- 每次运行先调 common.log_result(pid, 词条, status, detail)
- `if __name__ == '__main__':` 打印结果并可独立运行
- 失败禁止编造数据；fetch失败→log失败并返回失败
- 每次采集间隔 sleep(1)，对同一站点不要并发

## 测试要求
每个脚本必须实际运行一次并确认CSV生成、数据合理（对照看板v6/Excel中的实测值量级）。
