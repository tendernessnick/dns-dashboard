# v26 资讯分页与目录优化

日期：2026-11-12。

本版根据实际使用反馈调整资讯阅读、外链与目录。五部门模块集合、数值口径、规划编号不变；纯界面调整不采集或改写数值观测。本轮仅为议息卡增加必要的官方相关新闻。

## 资讯与图文

- 所有`ul.feed`（新闻、公司公告、问答及榜单）和图文容器均使用手动分页，取消内部纵向滚动、滚动渐隐与滚动拦截。不自动轮播，不拦截wheel或纵向触摸。
- 桌面在内容两侧显示箭头，窄卡和手机将箭头放在内容下方两端，页码居中。依据容器宽度调整每页数量；单页内容不显示无效箭头，首尾按钮禁用，按钮触控区域至少44px。
- 翻页、重算页数或切换公司面板后保持有效页码和可见焦点，不把焦点留在隐藏条目或禁用按钮。只控制显示，不修改NEWS、TOPS或REVIEWS。
- 新闻、图文和首页图文精选使用真实`a`元素整卡打开原文，保留新标签、noopener和noreferrer。不再保留“查看图文＋原文”双操作及重复的模块预览按钮；原文只接受http/https，无效链接显示文字空态。来源脚注、P号与溯源附录保留。
- 标题、摘要、参数、日期与配图来自已有载荷。图片待核对规则继续适用，不以新图片替换原始资料。TOPS仍只含已有的前5件详情，不能把分页后的可见数量称为完整榜单或销量。

## 议息模块

P16/P20保留会议日程、最近决议和官方查询入口，新增“相关新闻 · 近30天”分页卡片。来源分别为美联储官方货币政策RSS和欧洲央行官方新闻RSS；排除非货币政策决定、无日期、未来日期及非文章链接。前端同样按当前日期过滤，缓存过期后显示空态，日程仍保留。

本次保存美联储2条、欧洲央行4条官方资讯，每条保存发布日期、英文原题、中文译题、原文URL和来源；采集元信息记录真实UTC抓取时间。中文译题与原题并存，同一URL且原题不变时后续采集保留译题；可读取既有翻译缓存，不新增在线翻译依赖。

`collect_P16_议息日历.py --news-only`只刷新相关新闻，保留会议字段。获取失败保留仍有效的缓存并注明失败；官方近期无条目时，最多回退已有财经新闻里同时明确命中对应央行与货币政策主题的条目，无匹配如实空态。栏目首页和日程不伪装成新闻。`生成数据.py`沿用既有CAL透传，无需新增来源P号。

## 布局与目录

战略页P37集装箱运价与P38航空货运需求放在同一行，统一组名为“物流成本与航空货运需求”。保留SCFI点数与CTK同比的独立名称和单位，不将需求解释为空运价格。小屏按原响应式规则堆叠。

桌面（≥1280px）可将目录收成68px编号栏，悬停显示完整板块名，内容区同步拓宽；窄屏使用紧凑目录条与展开菜单，选择后收起，并支持Esc、点外部关闭与焦点恢复。桌面和窄屏状态分别保存，localStorage不可用时降级为内存，分享版跨部门可复用父窗口状态。展开和收缩后通过现有resize路径重绘图表。

另外修复1100px下品牌卡标题和状态标签挤出边界的问题，允许标题区域自然换行。
