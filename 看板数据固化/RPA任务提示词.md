# RPA 任务提示词手册

> 用途：以下条目因 **登录墙 / JS动态渲染 / 反爬强度高**，普通 requests 采集精度不足或无法访问，需要浏览器级（RPA）采集。
> 每个条目给出：目标、原因、操作要点，以及一段**可直接粘贴到 ZCode 定时任务的提示词**（本提示词已包含输出路径、CSV 列、upsert 规则与验收标准）。
>
> 使用方法：在 ZCode 中**本项目工作区**（即包含 `研报数据整理/` 文件夹的工作区）新建定时任务（CronCreate / 自动化），把「提示词」整段粘贴进 prompt 字段，按建议频率设置调度。
> 通用约定：CSV 均为 utf-8-sig；第一列固定为 `数据日期`（YYYY-MM-DD）；同日期已存在行则只更新数值列（upsert），不得删除历史行；采集完成后需回报本次写入的行数与数值。
>
> **路径约定（v2，2026-10-28）**：所有写入路径均为**工作区相对路径**（相对工作区根 `研报数据整理/…`），不再写死盘符——项目整体搬到其他盘符/路径后提示词无需修改。
> 代价是：任务**必须在本项目工作区内创建与运行**；为防粘错工作区导致数据静默写丢，每条提示词开头都有【锚点校验】，锚点不满足时必须停止而不是写往别处。
> ⚠️ 修改本手册不会自动更新已创建的定时任务（任务保存的是创建时的提示词副本），存量任务需逐条重建或更新。

**锚点校验句**（各提示词开头统一引用，含义：确认当前工作区根目录下存在 `研报数据整理/数据看板构建/看板数据固化/CSV数据/` 文件夹；若不存在，立即停止并回报"锚点缺失"，不写入任何文件）：

## P07 电子制造业工业增加值（工信部） · 建议每月1日-10日

- **目标**：规模以上电子信息制造业增加值累计同比（%），工信部《电子信息业月度运行情况》。
- **原因**：工信部栏目为 JS 动态加载，requests 拿不到列表。
- **操作要点**：数据通常在每月发布的《电子信息制造业运行情况》稿件中（文字表述"增加值同比增速x%"），逐月累计口径。

**提示词**：
```
【锚点校验】确认当前工作区根目录下存在 研报数据整理/数据看板构建/看板数据固化/CSV数据/ 文件夹；若不存在，立即停止并回报"锚点缺失"，不写入任何文件。
打开工信部运行监测协调局栏目 https://www.miit.gov.cn/jgsj/yxjhd/index.html 或搜索"电子信息制造业运行情况 2026"，
找到最新一期《电子信息制造业运行情况》稿件，进入稿件页提取：
1) 稿件标题与发布日期；2) "规模以上电子信息制造业增加值同比增长X%"（若给的是累计同比，记录累计口径）。
将结果写入CSV（相对当前工作区根）：研报数据整理/数据看板构建/看板数据固化/CSV数据/宏观数据-P07-电子制造业增加值.csv
列：数据日期,增加值同比%,数据来源,备注。数据日期取报告期月份（如2026-09-30）；数据来源填"工业和信息化部《…》稿件"；备注填稿件URL。
若该日期行已存在则更新数值列，否则追加。完成后回报：报告期、同比值、稿件URL。若当月稿件未发布，回报"未发布"即可，不要写入。
```

## 通用注意事项

1. **合规**：所有 RPA 限内部研究用途、低频访问（≤每日1次）；遇验证码/滑块一律停下回报，不得尝试绕过。
2. **失败处理**：任务失败回报失败原因即可，禁止编造数值补位；连续失败3次应人工复核来源是否改版。
3. **口径变更**：来源页面改版导致字段含义变化时，先回报样例数据，经确认后再改 CSV 列。
4. **新增 RPA 条目**： discovering 新受限源时按本手册格式追加条目（路径一律用工作区相对路径 + 开头【锚点校验】）。
5. **路径机制**：本手册路径为工作区相对路径，仅在**本项目工作区内创建/运行的任务**下正确；项目整体搬盘无需改提示词，
   但若把任务建到其他工作区、或改用 Windows 任务计划程序等外部调度（CWD 不可控），必须改回绝对路径。
   项目搬家后，已创建的定时任务绑定的是旧工作区路径，需在新工作区重建任务（直接复用本手册提示词即可）。
