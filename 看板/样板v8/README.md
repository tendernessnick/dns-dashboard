## 设计约定（确认后写入正式规范）

1. **红绿语义唯一**：红=涨、绿=跌（A股惯例，沿用 v7 的 `--up/--down`），只出现在涨跌幅、趋势线、涨跌方向上；环形/份额等结构图保持品牌蓝系。
2. **趋势线着色**：折线颜色随所选窗口的区间涨跌变化（涨红跌绿），与行情软件一致；期初基准虚线提供参照。
3. **无障碍**：红绿之外一律带 ▲▼ 箭头或文字（约8%男性红绿色弱）。
4. **动画克制**：一次性入场动画（描线0.9s、面积0.55s、数字滚动0.5s）+ 尾点呼吸圈常驻；`prefers-reduced-motion` 下全部关闭；resize 重绘不重播动画。
5. **固定槽位**：`布局.csv` 每个行(R)内卡片在生成时写入显式 `grid-column:span N;grid-row:行内序号`，卡片隐藏/缺失不引起邻居位移（v7 的 flex 自动流不复存在）。

## 已知边界

- `file://` 直开时 Amazon 商品图等外链图片需联网；无网时显示灰底占位，不影响版式。
- 现网数据窗口由 `词条注册表.csv` 的 WIN 驱动（本页同规则），序列长度不足 2 时显示「数据积累中」占位。
- 单文件版（打包单文件.py）会内联 data.js，样板逻辑不受影响。
