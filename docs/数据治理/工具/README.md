# 数据治理工具导航

工具保留原路径，避免影响测试导入和既有维护命令。日常采集入口是[run_all.py](../../../看板数据固化/采集脚本/run_all.py)，看板构建入口见[项目说明](../../../README.md)。

## 维护与回归仍会使用

| 文件 | 用途 | 使用说明 |
|---|---|---|
| [合理区间推导.py](合理区间推导.py) | 从现有历史推导区间，更新注册表及07核验文档 | 会写文件；由财报规则测试直接导入，保持原路径 |
| [迁移_TWS口径_20261111.py](迁移_TWS口径_20261111.py) | P45混合口径拆分及历史保留 | 已完成迁移；测试仍直接导入其中函数，不是日常采集入口 |
| [台账终版生成.py](台账终版生成.py) | 从两份注册表生成台账快照 | 手动导出，会写XLSX；当前运营事实源仍是注册表和溯源表 |

## 历史治理留痕

| 文件 | 定位 |
|---|---|
| [迁移脚本_阶段2_20261028.py](迁移脚本_阶段2_20261028.py)、[_迁移明细.json](_迁移明细.json) | 首期存储迁移代码与当时明细，不直接重放到当前数据 |
| [来源归一期_扫描脚本_阶段A.py](来源归一期_扫描脚本_阶段A.py) | 当期来源扫描 |
| [来源归一期_生成00分组表.py](来源归一期_生成00分组表.py) | 当期分组底表生成，执行会写入历史底表 |
| [验证_历史数据零丢失.py](验证_历史数据零丢失.py) | 针对2026-10-28备份的旧验证逻辑，不作为当前整理验收入口 |

阶段2迁移脚本和旧零丢失脚本的根目录定位仍按原位置向上两级，在当前层级会落到docs目录。旧零丢失脚本还依赖当前目录中不存在的历史备份，可能在没有比较文件时返回“0异常”。本轮仅记录用途与路径问题，没有运行这些脚本或改写其历史逻辑。

当前验证请使用[tests](../../../tests/)中的回归测试；文件整理另外采用逐文件指纹、文档链接和构建产物一致性核对。原审计底表见[首期治理历史记录](../历史记录/第一期治理_20261028/)。
