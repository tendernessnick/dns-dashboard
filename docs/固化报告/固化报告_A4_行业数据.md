## 三、失败 / 跳过及原因

### P97 新榜榜单目录 —— 失败（来源不可达，未写入任何数据）
- `https://ls.newrank.cn/rankmore`（含尾斜杠变体）返回 **HTTP 405 + 阿里云 WAF 安全阻断页**（"您访问的URL有可能对网站造成安全威胁"）。实测 curl、python-requests、完整 Chrome 头均被拦；web.archive.org 历史抓取记录中该页全部为 405 阻断页（CDX 查证），即存档爬虫同样被拦，无可用的存档镜像。
- 备选页 `https://www.newrank.cn/m/rank` 返回 HTTP 200 但为 Vue SPA 空壳（`<div id="app">`，无 SSR 目录数据）。
- 脚本已按约定重试三类入口并如实记录失败原因（采集日志 P97 详情）；**未编造数值，未生成 CSV**。恢复建议：换用可过 WAF 的出口IP/浏览器内核采集，或由新榜提供 API 授权后重跑。

## 四、实现与运行说明

1. **IDC（P44/P46/P47/P48）**：统一走 `idc.com/wp-json/wp/v2/press-release?search=…` 检索接口，标题过滤"全球稿"（含 Global/Worldwide，排除 India/Japan/China/Korea 区域稿与 Consumer 分品类稿），再从 content 解析"同比→X百万台→季度"；季度日期经 `parse_date_label('YYYYQn')` 落期末。P44/P47 抓到的已是更新的 2026Q3 稿（IDC 10 月发布），此前 Q2 实测值被自然滚动。
2. **Counterpoint（P43/P45/P49/P55/P57）**：SSR 正文正则解析；P49 解析页面份额表并自动选取最新季度列（Q2 2026）。
3. **P66 Amazon**：Cables 类目节点（16676470011）当前对非浏览器请求返回"Best undefined"空壳（无商品数据），脚本按预案自动回退至 zgbs/wireless（充电配件）类目，实际使用的类目记录在"数据来源"列；多行快照按 `key_cols=['数据日期','排名']` upsert。
4. **P69 FRED**：本机网络直连 `fred.stlouisfed.org` 全部读超时（多重试仍不通）。回退链：先查 web.archive.org 已有快照 → 无则 Save Page Now 触发存档爬虫回源抓取**同一 FRED 原始 CSV**（非镜像改写，内容与 FRED 完全一致：2026-09=7853）。所获为 FRED 官方文件原值，已在备注列注明获取路径。
5. **P71 统计局**：stats.gov.cn 响应慢，脚本内置 3 次重试；解析稿内数据表"通讯器材类"行（当月值/当月同比/累计值/累计同比）。
6. 全部脚本遵循 `_约定.md`：文件头注释、`run() -> (status, detail)`、先 `log_result` 后返回、同站请求间隔 sleep、失败不编造数据。全批经 `run_all.py` 完整复跑验证（12 成功 + P97 失败，结果与单测一致）。
