# 谷歌 Pixel Tag 防丢追踪器开售：对标苹果 AirTag，售价 29.99 美元

> 来源：IT之家 ｜ 原文：https://www.ithome.com/1/025/553.htm

> 采集说明：collect_P41_Apple新闻.py 正文段落照录；chips机械提取、摘要照录首段。

IT之家 11 月 11 日消息，谷歌对标苹果 AirTag 的防丢追踪器 Pixel Tag 已在美国市场正式开售，Android 用户可以通过智能手机内置的 Find Hub（查找中心）功能，追踪钥匙、钱包、背包等随身物品的位置。
Pixel Tag 于今年 8 月发布，售价为 29.99 美元（IT之家注：现汇率约合 200.6 元人民币）。与苹果 AirTag 及其他防丢追踪器类似，这款设备同时支持蓝牙和超宽带（UWB）连接，能够实现精准定位。包括 Pixel Watch 用户在内的 Android 设备用户，可以通过距离显示和方向指引相结合的方式，寻找丢失的物品。
Pixel Tag 内置扬声器，可以播放提示音，帮助用户在附近寻找物品。如果丢失的是手机，用户也可以连续按两次 Pixel Tag 上的实体按键，让手机响铃。用户还可以在 Find Hub 的设置中选择三档提示音音量，最高音量约为 80 分贝。
虽然 Pixel Tag 与 AirTag 的用途相同，但谷歌采用了不同的外观设计。苹果 AirTag 是小巧的圆形设计，而 Pixel Tag 则采用了更纤薄、修长的椭圆形造型。
具体来看，Pixel Tag 宽约 1.1 英寸（约 2.8 厘米），小于 AirTag 的 1.26 英寸（约 3.2 厘米）。由于采用椭圆形设计，其纵向高度为 1.8 英寸（约 4.6 厘米）。厚度方面，Pixel Tag 仅为 0.2 英寸（约 0.51 厘米），而 AirTag 的厚度为 0.31 英寸（约 0.79 厘米）（苹果将这一尺寸称为高度）。更纤薄的机身可能更适合部分用户，尤其是在钥匙扣等小型物品上安装时。
Pixel Tag 重量仅为 0.4 盎司（约 11.3 克），包含电池在内。
与苹果不同，谷歌为 Pixel Tag 配备了一个实体按键，用户可以直接按下按键操作，设备的使用方式也更加直观。
值得一提的是，谷歌今年 8 月发布 Pixel Tag 时，并未提及设备支持 NFC 功能。苹果 AirTag 利用 NFC 为捡到失物的人提供帮助，对方只需用手机轻触追踪器，就能打开一个显示物品主人联系方式的网页。而谷歌对 NFC 轻触功能采用了不同的设计：用户轻触 Pixel Tag 后，手机会直接连接到该设备的设置页面。
对于不在附近的丢失物品，Pixel Tag 则依靠谷歌在全球部署的众包定位网络。该网络接入了超过 10 亿台 Android 设备，工作原理与苹果和 Tile 的同类服务类似：附近的其他 Android 设备可以识别追踪器，并将其位置信息发送给物品主人。用户随后可以在 Find Hub 应用的地图上查看失物位置。
与支持 NFC 的设备不同，捡到 Pixel Tag 的人无法通过轻触设备直接获取失主信息。不过，当用户将 Pixel Tag 设置为“丢失”模式后，设备可以向捡到它的人显示失主的电子邮箱、电话号码以及一段简短留言，方便对方联系失主。
当 Pixel Tag 重新进入用户手机的连接范围后，系统会自动将物品标记为已找到。
此外，用户还可以通过 Find Hub 应用，将 Pixel Tag 的位置共享给最多 10 个人。这对于家庭共用物品尤其方便，例如多名家庭成员都会使用的汽车钥匙。
